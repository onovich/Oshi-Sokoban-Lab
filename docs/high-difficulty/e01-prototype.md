## 作者证据区（包含解题结构）

### 盘面与隔离

内部任务来自 [E01 任务书](experiment-briefs.md#e01)。仅有普通推动、静态 Goal、两格竖形 A 与单格 B；无旋转、编号、Fake、Spike、Rain 或 Gate。所有 Goal 初始可见。

```text
##...
#.B.G
GA.#.
GA...
@####
```

同一个 A 占两个格。`G` 为 Goal，`#` 为墙，`.` 为普通地板。坐标从左上角 `(0,0)` 开始。

- 原型：`lab-e01-shared-passage`；对照：`lab-e01-independent-passage`。
- 对照**仅移除 `(3,2)` 的墙**；物件、出生位置、Goal、玩家和规则完全相同。两版刻意共用实体 ID，作为相同物件的因果对照；关卡与进度 ID 独立。
- 只加入 `mastery-v2.labLevels`／`labGroups`。正式顺序、120 槽蓝图、冻结关、P1–P10、引擎规则和持久化格式不变。

### 必要关系，而非规定一条路线

A 先右移开放 B 的推侧。B 可向右暂存；若直接进入右端 Goal，它会堵住玩家从右边绕回 A 的通道。玩家需要在 B 未完成时再次调整 A，之后才具备可执行的收尾条件。

测试允许另一种合法做法：玩家先挪开 B、绕过去，再把 B 推回初始位置，然后调整 A。这仍然利用了 B 的未完成中间态，不因停靠坐标不同判为绕解。A 与 B 的最后完成次序也不强制唯一。

采用两类交叉证据：

1. 现有类型化事件序列证明 A 开路 → B 腾位 → A 回调 → B 最终推进不可绕过；对照则出现绕过此顺序的解。
2. 实验室专用无剪枝搜索调用真实 `move()`，禁止“已经离开原位的 A 在 B 未完成时再次被推动”。原型穷尽仍无解，对照可以完成。该条件不指定 B 的暂存坐标；A 回调后仍未覆盖 Goal，不以必然的最后获胜推动冒充技巧。

此搜索只接受无回合相关机制的纯空间盘面，拒绝雨、刺、门、可移动目标、假物件、数字和时间／步数上限。不复制推动规则，也不扩建正式求解器。状态去重忽略 Undo 历史；语义回调禁令必须是纯状态局部条件。后续 [E06](e06-prototype.md)为有序事件增加了单独的有限前缀状态入口，不能把历史依赖私自放进纯状态回调。

### 机器结果

| 检查 | 原型 | 只开一格的对照 |
| --- | --- | --- |
| 真实引擎可回放 | 18 步 / 5 推 | 9 步 / 5 推 |
| 禁止上述语义关系 | `proven-unsolved`，穷尽 76 状态 | `solved`，9 步 / 5 推 |
| 现有事件命题 | `necessary` | `bypass`，预期结果 |
| 原目标 / 难度证据 | D5 / 本组作者约 D3，未逐关评分 | D3 / 同一组反馈，未逐关评分 |

步数来自逐步 BFS 的最短移动见证；推动数是该见证上的计数，不能由此额外宣称全局最少推动。原型无禁令 BFS 找到解前探索 112 状态；这不是“全图只有 112 个状态”。预算耗尽始终返回 `budget-exhausted`，不作为无解证明。

默认作者搜索窗口中存在多种宏顺序（包括两物件最后完成换序与 B 回推）。本候选不宣称唯一宏策略。自动事件里程碑之后的最佳见证尾巴为 2 推；这只是预定理解点的代理，不等于真实玩家最后顿悟发生在那里。

诱人错误的回放另有测试：A 开路后连续把 B 推到底，剩余局面无正常推动解；Undo 一次后恢复可解，Restart 恢复初态。禁止关系的穷尽搜索同时覆盖其它走位，不能仅以这一条错误回放充当必要性证明。

### 变异与元素职责

原型现有变异工具产生 **15 个有效结果**：

- 删除 A 或 B：各自留下可解小题，但原双物件命题被绕过。
- 删除任一 3 个 Goal：不再有完整覆盖解。
- 封闭任一 10 个初始空地格：无解。这些格承担可达推侧和绕行通道，不是搬运长度填充。
- `(0,4)` 为起点，用于让左侧两个 Goal 都保持可见；已有可读性标注。起点、实体和目标占格不做制造非法初态的封墙测试。边界墙是布局边界；对照单独检查 `(3,2)` 这处资源隔断。

没有 `invalid`、`inconclusive` 或未解释的 `unchanged` 结果。现有工具把无效变体归类过强的通用缺口未在此扩写；本关测试显式拒绝以 `invalid` 通过。15 项只覆盖该工具声明的变异空间，不冒充任意地图改动的全覆盖证明。对照故意允许绕解，作者面板禁用以必要命题为前提的删除审计，并解释原因。
