# 分章节设计与批量评审计划

2026-09-29。落实作者“先设计一批、内部试玩，再整批给作者审查”的工作方式。

执行更新：BA1、BA2、BC1、BA3 已制作为 [LAB 41 折廊](ba1-return-passage.md)、[LAB 42 转廊](ba2-shared-bay.md)、[LAB 43 折汀](bc1-offset-bank.md)、[LAB 44 复廊](ba3-two-stage-parking.md)。折廊有视觉辨识反馈，记录为 AI 初审待改进；复廊的旧版有试玩，新版不能继承通过，均不计合格名额。验收采用[版本化台账](level-acceptance.md)：AI 为初审，作者为最终；每关完成后验证、独立提交并推送，不向作者逐关发起验收。

当前批次台账：5 个入库可玩候选，3 个 AI 初审通过（转廊、折汀、[借汀](bc2-borrowed-stop.md)）、2 个 AI 待改进（折廊、复廊）、0 个作者最终验收。复廊现版本已由未见该题的另一测试者重测，仍有长条分组和目标遮挡反馈。借汀有行动前主动延迟完成、预测停点用途的迁移证据，尚不能校准 D5。更高阶 [BC3 双向交接原型](bc3-rejected-search.md)因存在同成本绕解淘汰，不计成品；暂转向 BB 的可推 Goal 工作位置练习。整批目标仍为 12 个合格候选，不把局部完成等同整批交付。

**当前交付：5 张入库候选、相应机器审计与 AI 试玩报告、1 张有可复现反例的淘汰原型、章节规划；不是 12 张已实现地图。** 下列 BA/BB/BC/BD 编号用于设计，已实现项另有稳定 ID 与 LAB 历史编号。正式 120 槽、60 基础关及已保护实验盘面不变。下面难度均为设计目标，既有作者评级另列。

## 一、从已有迭代中保留的判断

- 窄门 → 近岸 → 再借庭是作者认可的 D4 → D5 → D6 教学参照。保留问题冲突，逐步增加协调要求，比从难题截取一个已完成大半的残局可靠。
- 间庭、叠庭证明有趣的挑战可以超过当前明确可复述的技巧。不必一直增添前导；先检查是否真缺前置，再允许玩家挑战、暂离。
- 转岸 → 涉岸的作者反向迁移，是把 Goal 当作空间资源而非只当终点的有价值证据；不能因作者没有念出术语就说没学会。
- 回汀与择汀正确路线相同，更多是记忆唤起。隔汀的口述更接近明确的因果解释，但尚未证明稳定迁移。
- 交岸回访中，“横条完成后已无解”被真实 move() 反例否定。禁止从一条成功路线反推所有解法都必须按同样次序。
- [寻汀 AI 实验](../playtests/2026-09-29-ai-self-stop.md)支持基础发现用途，不支持高难或跨关迁移。AI 初筛可发现规则可读性、候选解和卡点；不能代替作者或真人难度校准。

## 二、章节是能力分支，不是编号长链

五幕仍负责整部课程节奏，以下章节是横跨五幕的技巧路线；不是新增六幕。旧关整体归属待课程映射，不移动其稳定 ID。表中的箭头是推荐学习关系，不是本轮修改运行时解锁。

| 章节 | 反复练习的核心关系 | 现有可用参照 | 新生产的缺口 |
| --- | --- | --- | --- |
| A 空间借还 | 让出通路时，安排以后如何重新取得推侧 | 教学链 A/B/C；临庭、望庭；间庭与叠庭为可暂离挑战 | 从留路到恢复通路的陌生变式，避免只记固定方向 |
| B 目标与工作空间 | 最终目标位置与中途有用位置未必相同 | 转岸 → 涉岸；基础可移动 Goal、空 Goal、数字/Fake 课程 | 暂存、推/穿切换、任务身份与运输次序的协调 |
| C 雨中站位 | 先决定要站哪，再安排提供该位置的阻挡物 | 寻汀为候选；隔汀有局部口述证据；交岸/候岸/泊庭仍为挑战或待验证 | 自停靠 → 为他物停靠 → 释放停靠资源；变式必须改变决策 |
| D 远端通路 | 本地输入的可行性由远端布置决定 | 冻结 Gate 基础三组 | 去程与回程分别准备、推门与通门主动切换 |
| E 回位调度 | 重置是物件回到 origin 的边，触发侧与出口可分别安排 | 冻结 Spike 两组及后续组合 | 揭示后的 origin 借用、释放、完整占格调度 |
| F 资源交接 | 两条技巧共同约束同一个中间状态 | 间庭/叠庭为空间挑战参照；雨岸为 Goal × Rain 候选 | 真正的 AND 综合，不能由两个独立小题拼成 |

前置关系：

- 完成各自规则识字后，A/B/C/D 的基础路线可自行选择顺序；题目需要具体技巧时才挂对应前置。
- F-空间综合要求 A 的借还与收尾能力；F-雨地综合要求 B 的工作空间与 C 的停靠释放；F-远端综合要求 A 的回程与 D 的出口条件。
- E 的正式揭示仍放在第 70–75 槽。H1–H8 仍分散到此前的其他章节新增桥接关，Spike 是损失有用布置的辅助障碍，不改冻结盘面，不连续堆八道避刺题。
- 不把“所有分支全通”设为任一综合题的前置。已学局部技巧不保证综合题容易；综合本身可以是挑战。
- 数字/Fake 不是消失了：保留基础与 I 系列计划，归 B 的分配支线；本批暂不同时扩写所有机制。

## 三、下一生产批：12 个候选任务书

每章三张只是本批规模，不宣称每种技巧都三关结束。所有初始任务需有实际未完成工作，禁止用预摆好关键局面的简单收尾凑教学题。每卡先写命题测试与真实 move() 可解回放，再产生地图。地图尚不存在时所有必要性均为假设。

| 设计 ID / 目标 | 单一总命题与资源冲突 | 自然错误计划与反证 | 必要中间态 / 解耦对照 / 淘汰条件 |
| --- | --- | --- | --- |
| BA1 / D4 | A 让路后仍须保有回收它的推侧；让路不是永久停放 | 把 A 推到底最省事，但之后站不到回推侧；应能由边界看出 | A 停中间，先通过再回收。增独立回收通路应解除要求；只多走一圈而无决策变化则淘汰 |
| BA2 / D5 | 同一绕行区先服务 A，后服务 B，任务间必须交接 | 把 A 完成就封住 B 所需站位 | A 暂离最终位置，B 建立中间态后 A 再归位。增第二绕行口应解除交接；若可逐件完成则重构 |
| BA3 / D6 | 先前有用的暂存位在回程变成障碍，计划要包含撤销条件 | 重复 BA1 的“停这里”会封闭不同的回程 | 保留熟悉入口而改变回程需求；两阶段停放应不同。开放独立回程应解除二次调整；仅旋转 BA1 不收录 |
| BB1 / D4–5 | 可推 Goal 的工作位置必须越过看似合理的最终位置 | 对齐即停，导致另一真实 Block 没有操作空间 | Goal 先越位让出推侧，之后回收。增侧面空位应取消越位需要；必须检查 Goal 全部推/穿替代路线 |
| BB2 / D5–6 | 推 Goal 和穿 Goal 服务两个阶段，要主动制造和撤销受阻条件 | 一直推 Goal，或把它永久钉死，分别失去站位或终点 | 制造受阻以穿过，再从新侧解除阻挡恢复移动。加入独立步行道应取消切换需求；只示范一推一穿不是完整题 |
| BB3 / D6–7 | Goal 暂存位置同时决定 Block 的运输路径和最终落点 | 先把 Goal 送到终点，运输通路反而不成立 | Goal 中途作空间配置，Block 到中间态后才收尾；独立运输通路应解耦。若两子题可分别完成则不算综合 |
| BC1 / D4 | 目标 Block 自身提供玩家进入所需推侧的停点 | 直接接近目标行后，滑行越过需要的站位 | 承接寻汀关系但改变必须先调整哪条轴；增加静态止挡应解除依赖。不能复用寻汀输入序列且仍通关 |
| BC2 / D5 | A 为 B 提供停点，但使用后必须能释放 A | A 靠边就能挡住，却再也无法取得移动 A 的推侧 | 在可回收位置停 A，使用后正常移开。固定止挡对照应免去 A 的准备；禁核心关系无解，禁某条路线不够 |
| BC3 / D6 | 同一物件先作停点、后作任务物；新布置改变回收方式 | “刹车用过就归位”导致第二次所需站位丢失 | 先交接停止作用再释放原停点。独立第二止挡应消除交接；若没有真正二次用途则退为练习，不抬难度 |
| BD1 / D4–5 | 为取得出口后的推侧，应选择正确入口方向，而非最近入口路线 | 最近路线能传送，却落在无法推动的一侧 | 先安排接近方向再进门。增出口本地绕行道应解除方向选择；不能靠暗示出口方向或遮挡制造难度 |
| BD2 / D5–6 | 远端受阻使入口转为可移动物件，解除后才作为通路使用 | 总想先清出口，反而错过移动入口所需状态 | 阻挡出口→移动入口→解除→通过。控制块同时有后续任务；免费开关或演示三动作不收录 |
| BD3 / D6–7 | 能去不等于能回，端点移动前必须准备后续的接近方向 | 第一次传送成功，但把回程入口推侧永久封住 | 去程布置留出回程调整；独立返回通路应解除预留要求。需跨 Gate 真实动作检查，不能套普通箱子死锁规则 |

这 12 个是候选池，不是正式新增名额承诺。BA/BB/BC/BD 的内部名称仅开发可见，玩家标题使用中性文案。每张另存：几何锚点、与参照关的关系差异、被保留的错误方案、因果测试、求解预算与结果、试玩暴露、保留/返工依据。

### 生产顺序与批次交付

1. 先 BA1–3 与 BC1–3：六张组成两条不同技能线，内部完成规则回放、关系反事实、解耦变体与变异检查。
2. 再 BB1–3 与 BD1–3：复用已核验规则；新行为缺证据先补 Unity/行为对照，不编新规则。
3. 每条线先让新上下文 AI 按玩家条件试玩。新候选回访不可再称盲测；平行首次暴露必须换未见题上下文。保留完整输入和即时假设，通关后才问关联。
4. 内部筛掉重复/无冲突候选，允许返工替换，不用填充关凑 12。作者得到一个整批入口和章节说明，只标当前建议顺序、既有难度与未知，不显示内部命题和解法。
5. 本批不逐张打断作者邀请试玩；形成至少两条完整的可玩章节小段再提交评审。届时交付“实现数 / 淘汰数 / 未知项”，不得把本任务书当作地图已完成。

## 四、如何依据试玩打磨

| 证据 | 处置 |
| --- | --- |
| 基础题快速通关，能解释关键关系 | 保留基础用途；用陌生关系变式检验迁移，不因简单盲目加墙 |
| 通关但仅能回忆方向/画面 | 记录为复现；下一题改变关系中的一项条件，不能直接宣称教学成功 |
| 卡在规则或画面歧义 | 修表达后用新样本重测；不计作难度 |
| 误判死局但引擎仍可解 | 分别记录挑战盲区与缺少前置的可能；不要立刻加前导或给“仍可解”保证 |
| 核心关系被绕过 | 验证是合理替代策略还是命题失真，先修命题/结构，不强封全部替代解 |
| 解耦后仍要求同一技巧 | 资源冲突解释可能错误，退回设计；预算耗尽记未知 |

每张通过内部筛选后，附一页不剧透作者试玩卡；其背面保留设计证据、AI 意见、未解决风险。作者难度、AI 自评、陌生真人样本分别存放；放行只引用[统一试玩协议](../playtest-protocol.md)，不新建更低门槛。

## 五、无监督生产的当前边界

可以无监督推进的是候选构造、自动证伪、路线回放、AI 可用性筛选、章节候选整包。尚不能无监督确认 D8–10 或“玩家已经学会”。首批目标是多条可靠 D4–7 关系弧，不再填标签制造 D10。待跨机制生产质量稳定，再进入 F 的 D7–10 综合候选；Spike 长期信念仍须由未提前见揭示的玩家按课程顺序验证。
