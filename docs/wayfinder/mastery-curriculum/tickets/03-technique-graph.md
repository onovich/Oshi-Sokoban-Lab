# 哪些技巧值得反复练习、迁移和组合？

从现有 63 关、公理—后果图、求解器关键事件和作者游玩反馈中提取技巧节点，区分“知道规则”与“会主动利用”。候选节点包括推侧保留、完成顺序、稀缺目标分配、暂时破坏完成、Fake 支点、origin 出口管理、远端换侧、Goal 模式切换、Rain 自建停点、Gate 方向携带和远端状态控制。

完成条件：每个节点有前置、典型失误、最小练习、迁移变量、可组合节点与可能达到的难度上限；删除只是机制换皮而无新推理价值的节点。
