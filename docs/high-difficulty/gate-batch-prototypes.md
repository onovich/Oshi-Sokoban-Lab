符号：E/X 为双向配对单格 Gate，B 为真实单格箱，□ 为静态 Goal，@ 玩家，# 墙，. 普通地面。均晴天、数字0，无其他物件。坐标零起点。

## BD1：两次选择入射方向

拟 ID `lab-bd1-direction-choice`，基础迁移，目标难度仅 D3–4 假设。

```text
...####
.E@#.X.
...#.B.
####□#.
```

7×4。E(1,1)，X(5,1)，B(5,2)，Goal(4,3)，玩家(2,1)。先需箱子右侧站位，左推后再需上侧站位；出口房不能本地绕行取得两侧，须返回入口更换方向。

- `ULLDRDLURDLD`：12输入、2推；实际 move 图搜索130状态找到解。
- 禁 E 向右或向左穿越，分别穷尽69状态无解；过滤领域事件，不是禁止整个方向键。
- 仅开(5,3)，禁向右穿越仍可解 `LDDRRULURDLD`，152状态。
- 最近输入L并非永久失败：LR回到原局面，允许低成本验证；LDR把箱推到右边界后54状态无解。
- 左入口保留两条接近路线，不把单通道强迫动作伪装为选择。右下(6,3)是对照绕行连接，不宣称原解必需。

可能过于简单。它的价值应由后续迁移验证，不能因为有两次传送就抬为高难。

## BD2：先制造入口站位

拟 ID `lab-bd2-shifted-entry`，标题转隙；目标D5尚未校准。拟前置BD1。

```text
#..####
#E@#.X.
...#.B.
...#□##
```

同一箱子现在还负责阻挡出口下方。玩家从上方输入时，不是穿越，而是推动入口向下；下移后左侧才有入射空间。箱子任务与门的条件耦合，不是两题串联。

独立设计复核：这是利用**初始已有**阻挡来制造入口站位，不是主动制造阻挡，也不要求清除向下出口后沿同方向通过。原批次BD2所要求的完整“制造—撤销”关系仍待生产；此原型只能作为其中的基础迁移候选。两题的迁移测试需玩家已知方向保持和远端受阻可推门，否则只能算规则发现初筛。

- `ULDDLDRDLURDLD`：14输入、2推门+2推箱，128状态。
- 禁所有推门25状态无解；禁入口下移50状态无解；禁 E 向右/向左穿越100/89状态无解。
- 仅开(0,1)：无需推门，`DLLURDLURDLD`获胜，45状态找到解。
- 局部因果：前缀UL后，箱在(5,2)时向下推动入口；仅把箱移至(4,2)，同一输入变为穿越。由真实move产生事件，不另写规则。
- 12个普通空格逐封墙均无解。移除了无必要的(6,3)。这仅证明局部删格结果，不是全局最小性。
- 错误近路LDR之后26状态无解。
- **一次推门也有效**：`ULDRDDLLURDLURDLD`获胜；最短解第二次推门只是缩短绕路，不能要求“必须推到底”。
