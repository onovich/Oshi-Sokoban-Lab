# 怎样让避刺直觉充分成立后再公平地打破？

设计一条跨早期基础课和中后期进阶课的 Spike 认知弧，而不是连续三关的短前导。Spike 先在至少三个非 Spike 关卡族之间以新增桥接关的形式分散出现，只承担辅助障碍：封锁推侧、破坏诱人捷径、限制完整 footprint 或截断 Rain 停点。不得为此修改任何已验收盘面。桥接关的标题与任务仍属于所在时期的主要技巧；预期解零触刺，触刺只会损失当前布置并播放清晰销毁／重生演出，绝不能暗中帮助通关或抢走主要命题。

这些暴露之间保留非 Spike 关卡作为孵化间隔。只有盲测显示玩家会主动绕开 Spike，并把接触预测为“销毁、回出生点、丢失当前位置”，才安排专门 Spike 关卡族。该族第一关构造按“永远避刺”表面无解、但 origin 与接触路径静态可见的盘面，并首次让 `object-reset` 成为必要事件；之后再迁移到 origin 占用、换侧、远端触发和组合。

完成条件：至少提供首次威胁、跨三个其它机制族的分散桥接关、孵化间隔、专门揭示、迁移和综合候选；逐关列出预期信念、主要技巧、核心事件、删除 Spike 变异、禁用 `object-reset` 的结果和盲测问题。辅助关禁止重置后仍有解且删除 Spike 会产生捷径；揭示关禁止重置后无解；冻结清单证明旧关零变更。当前 19–21 可改写、拆散或后移，但在作者验收前不是约束。
