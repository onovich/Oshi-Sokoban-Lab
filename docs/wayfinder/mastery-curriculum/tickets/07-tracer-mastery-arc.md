# 纯空间关系能否形成高于 P 系列的规划难度？

决策已更新（2026-09-04）：P1–P10 保留为作者 D3–4 练习，不强行加难。先按[六张任务书](../../../high-difficulty/experiment-briefs.md)制作纯空间 D5–6 原型；题材只含普通推动、静态 Goal、完整占格及不可旋转形状。任务书完成不等于本 ticket 的原型与校准完成。

开始原型所需的设计假设、术语与已有锚点已具备，无须等待 01／03 的全课程实测校准完成。与 08 按单个原型迭代：原型和机器证据就绪后即可送测，反馈再用于重构；完整生产弧仍受阶段放行限制。

E01 已完成首轮：[作者反馈](../../../playtests/2026-09-04-author-e01.md)为整体约 D3、几乎无需计划改变，高难目标未通过。保留现版本作练习／对照；下一候选先审查局部安排与后续任务是否真正相互约束，不按任务书编号机械扩写，也不把事件顺序更多视为推理更深。此 ticket 仍为 open。

按[结构复审](../../../high-difficulty/post-e01-review.md)推进的 E06，现已与[短庭](../../../high-difficulty/e06-scaffold.md)一同获作者组验收：08=D4、07=D5、06=D6。作者解开 08／07，06 在未解出后观看完整演示；不把该过程补成独立通关。[原始时间线](../../../playtests/2026-09-04-author-e06.md#author-acceptance)

当前组已在实验室按短庭 → 旁路 → 回环整合，盘面和稳定 ID 不变。教学可选择另加前置或接受现状，尚未要求立即制作补课关。后续已制作 [E02 折返庭／侧庭](../../../high-difficulty/e02-prototype.md)，以双形状暂存交接探索更可归纳的技巧，机器检查通过、作者评级待定；[Rain 变式卡](../../../high-difficulty/e02-rain-variant.md)只记录继承与变化条件。单组验收不等于本 ticket 所需的不同候选与陌生校准全部完成，不直接批量扩到 D7–8。

每关先写规则／命题测试，再有最小盘面、真实求解回放、语义必要性、有效解耦对照、宏策略与元素变异；预算耗尽或无效变体不能作证明。前置关系引用[策略主线](../../../high-difficulty/design-guide.md#strategy-lines)，评级与放行只引用[试玩协议](../../../playtest-protocol.md#high-difficulty-pilot)。

后续顺序：纯空间 D5–6 → D7–8 → 峰顶作者与专家验收 → 分配、Goal／Rain、Gate、Spike 的策略迁移 → 必要组合。不等待 Spike 铺垫地图先完成，也不因为某张卡写了 D6 就继续批量扩写。全弧仍需间隔回访和迁移证据，但第一批不提前加入这些机制。

上行是地图生产的证据顺序，不限制现在思考跨机制关系：每次规划新机制教学，都与 ticket 03 一起检查旧技巧及相似底板的变式潜力。两条内容扩展方向与教学取舍只在[总纲](../../../high-difficulty/design-guide.md#technique-growth)维护。
