# 第三版结构深化

参考原始方案 01。以下尺寸是为实时模型补充的设计值，不是从二维原画准确测得的工程参数。Blender 单位按米；可编辑参数位于 tools/salvage_robot.py、salvage_details.py、salvage_environment.py。

| 部位 | 本次参数与连接 | 实现 |
|---|---|---|
| 角色 | 约 1.92 m，保持 52 骨骼 T-pose | 原创网格，原有动作重定向 |
| 胸部装甲 | 浮动胸盾、锁骨分缝、半径 9 mm 六角螺栓、垫圈 | 各零件绑定胸骨；不增加变形骨 |
| 背部 | 双侧 91×81 mm 检修盖、三道散热槽、中央脊柱节段 | 薄盖与黑色凹槽分层 |
| 膝 / 肘 | 双耳支架、垫圈、内嵌轴端 | 支架绑定对应下肢 / 前臂，保持关节间隙 |
| 液压组件 | 14 mm 半径缸筒、7 mm 半径活塞杆 | 布置于前臂、小腿、大腿背侧；分段导管不跨越活动关节 |
| 头部 | 耳侧嵌套轴承、颊部三道进气槽、8 mm 高视窗 | 保留黄竖条与楔形头盔 |
| 脚部 | 三道甲片分缝、四条独立鞋底纹块 | 脚掌和脚趾保持原有骨骼 |
| 墙体 | 600 mm 厚，7 段不规则顶部断面 | 整块混凝土挤出网格，替代顶部堆叠石球；顶缘露出浅色断层 |
| 钢筋 | 半径 12 mm，折弯端部 | 从高墙破口伸出，属于环境陈设 |
| 钢柱 | 430×460×90 mm 底板、四锚栓与三角加劲板 | 钢架增加斜向支撑 |
| 地砖 | 1.575 m 面宽 / 1.6 m 间距 | 收敛面内色差、增加边缘剥落 |
| 箱体 | 保留原外轮廓与碰撞尺寸 | 新增凹板、铆钉、提手、竖向加强筋 |

本次优先解决原画中的结构层次与断裂轮廓。连接方式用于视觉可信度，不代表机械工程强度验证。微小紧固件在全景中形成边缘高光，近景中才逐个可见。

## 仍有差距

原画的局部手绘磨损、布料以及大范围峡谷构图尚未完全复现；本轮保留既有场地尺寸、角色动画和可推箱交互。液压杆为刚性分段视觉结构，尚未做实时伸缩机构约束。
