# 哪条技巧弧最适合作为 1–10 的端到端样板？

选择一条最能覆盖认知建立、迁移和必要组合的技巧弧，先做少量 tracer 关而不是全面扩写。候选优先级：Spike / origin 远程边、推侧访问权、Goal 条件式地形。

完成条件：样板覆盖多个难度锚点，至少包含一次延迟回访、一次跨机制迁移和一个 8–10 候选；每关先有失败的命题测试，再有最小盘面、求解回放、绕过测试和变异审计。
