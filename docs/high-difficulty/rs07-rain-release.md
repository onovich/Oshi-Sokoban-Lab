# 回汀：检验“暂时挡住不等于无法退出”

2026-09-28。LAB 37，目标 D3 未校准。独立候选，不再承诺一关教会交岸。

## 作者明确反馈

交岸末轮第15步：小块下移是无心操作，未预期收益；横块继续右推似乎被小块堵住，未意识到小块仍可移出。助手确认可解后，作者知道如何完成，但明确不是独立顿悟。这比“不会绕行停靠”更准确；不能把提示后完成记为迁移成功。

交岸保留挑战用途，原盘面不改。已有前导的机器证明不构成教学成功。新的局部问题是：能否在操作之前检查一个中间布置的退出侧，而非仅判断其当前阻挡。

## 本次改变

5×4 雨天完整题，两件真实物品都未完成，无数字、Fake 或新规则。横块需向右运输，途中小块挡在其下方；同一横块也给玩家提供接近小块右侧的停靠边界。小块有左侧最终任务，便于让“移出去”成为清楚的子目标。不是原题残局，也不预先完成目标。

简化边界：本关小块左移后可以收尾，未覆盖原题小块的全程返运。只检验“可退出阻挡”的发现，不宣称解决全部协调。

## 证据

真实 move 求解回放获胜；禁止“横块 (2,1)→(3,1)，随后小块 (3,2)→(2,2)”的有序事件组合，搜索 proven-unsolved。这个顺序不是最终覆盖的同义表达。

局部因果对照：横块到位后，玩家从右下上行停在小块右侧，能将它左推；在同一状态移除横块则滑到顶边。该移除仅为因果干预，不冒称有效替代关卡。不宣称元素最小化、唯一策略或实测难度。

## 试玩

先只玩回汀，不自动下一关接入交岸。观察是否预测小块的退出方式、是否出现合理的计划改变；作者若仍报告简单无收获，不把动作通过当作学会。后续回交岸只能检验迁移，因已获提示，不再算原题陌生独立发现。暂不扩写更多相似关。
