## 新增隔离：隅庭

内部目标 D3，未实测。5×4，仅竖物 A 与横物 B，移除单格物及其任务。A 初始已位于右侧 (3,1)，B 在 (1,2)，玩家在 (1,3)。集中训练作者在半庭遇到的剩余上方通路需求，不要求再次发现三方暂存安排。

测试：正常求解回放胜利；禁止“A 下移 → B 再操作”无解；连续两次上推完成 B 后无解；在右端增加 (4,0)、(4,1) 组成一个独立绕行口后，同样两次上推完成 B，且不再移动 B 仍有解。这个对照改变一项通路条件（两格），不是单格变体。删除与封墙审计发现 (2,3) 无用，已从新图去除后重跑。

玩家可见标题及关前文案不解释顺序。先尝试隅庭，再返回半庭，检验能否独立识别上方通路仍有用途。机器证明只说明结构存在，不说明教学已经奏效。

依据：[作者反馈](../playtests/2026-09-07-author-e04.md)。不能因底板相似或求解器通过而宣称已教会。

## 隔离：浅庭

目标 D3，非实测。移除横物及其目标，剩下竖物 A 与单格物 C。保留右侧竖目标和左下单格目标。裁去三个不影响关键关系的空格，使用现有普通推动规则。

内部命题：C 的终点同时是 A 的上推站位；应先让 A 离开，再完成 C。不强制 C 必须首先推动，也不强制最后从某一方向进入目标。

机器合同：真实求解回放；禁止 A 上移后再操作 C 则无解；C 提前完成的实际路线导致无解；只开放墙格 (0,2)、禁止箱子利用新增格，同一路线之后可以继续解完且不再移动 C。由这个对照说明站位冲突，而非“某种形状必须最后完成”的规则。

## 恢复协调：半庭

目标 D4，非实测。沿用合庭三物件底板，横物预先到 (2,2)，单格物预先到 (3,4)，玩家在 (2,1)。省去自行寻找初始暂存布置，但仍需协调横物、竖物和单格物。

机器合同：真实求解回放；禁止“横物下移 → 竖物上移 → 单格物再操作”则无解；提前完成 C 的实际路线失败。与浅庭不同，只打开 (0,2) 并不能挽救这条路线：横物已经下移，增加了共享空间约束。测试保留这一差异，不把失败的解耦假设写成成功证据。

本题是协调桥梁，不是严格只改变一个变量的定界关。它与合庭仅初始安排不同，可能仍不够简单：若作者仍只能跟随演示，退回实验池，继续拆分三方关系，不认定学习链通过。
