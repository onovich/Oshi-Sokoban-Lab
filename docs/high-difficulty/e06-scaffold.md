## 内部设计记录（含技巧，不在玩家界面显示）

### 盘面与降低的负担

```text
####G
...C.
..AG@
#.AG#
```

A 是不可旋转的两格竖物，C 是单格真实 Block，G 为静态 Goal。坐标左上角 `(0,0)`。新关为 5×4 / 14 格可进入区域 / 两个物件；两难版均为 6×5 / 三个物件。不引入编号、真假、刺、门、雨或特殊推力。

保留长物、下方竖目标、上方运输横排、右侧目标出口之间的关系；抽掉 B 的争用与前期摆放，把上方收尾缩短一格。A 从尚未完成的中间位置开始，三个 Goal 全部可见，不依靠隐藏在物件下的目标教规则。不是把回环先替玩家走若干步后展示完全相同的残局，也没有预填难版的进度。

总命题是：**先借出长物占住的返回站位，取得另一物件的推侧，再完成两件任务。** 自然第一计划可能是朝最近的目标移动，但必须由盘面自己否定；这只是设计预期，不是已观察到的玩家想法。

### 与两难版的精确对应及限制

| 空间关系 | 短庭 | 回环 / 旁路中的对应有效策略 |
| --- | --- | --- |
| 长物让出返回站位 | A `(2,2)→(1,2)` | A `(2,3)→(1,3)` |
| 玩家取得小物左侧推侧并使其前进 | C `(3,1)→(4,1)` | C `(3,2)→(4,2)` |
| 用后完成长物 | 下方两格 Goal `(3,2),(3,3)` | 下方两格 Goal `(3,3),(3,4)` |

关键互动只平移一行，形状与方向不变。机器用难版的真实回放在两张难图上分别走到胜利，并验证该映射事件序列发生，不只是因为两张图都出现相同图标就宣称技巧相同。

回环必须使用这段关系，但在此前还需协调 B、C 与 A 的前一个暂存位置；短庭没有把这部分多阶段规划教完。旁路也允许这条策略，但新增返回格使它存在其他解法，所以**这段技巧不是旁路的唯一必要策略**。这张练习教的是共同可用的一个关系，不给整道难题的固定顺序；后续是否还需要另一层简化，依据作者重试结果决定。

允许玩家在已经取得推侧后，先把 A 部分移回再推进 C；最终仍需完成所有物件。首次过强的事件顺序误将这种等价操作排除，现已删除该限制；不把作者的一条五推动路线定成唯一答案。

### 测试与机器证据

沿用公开 `createGame()` / `move()` / `undo()` / `restart()`、实验室无剪枝搜索、类型化证明条件与 App 导航边界；没有新求解器或规则 API。

- 短庭：可回放见证 14 步 / 5 推；无剪枝搜索探索 136 个状态后找到。推动数是最短移动见证上的计数，不另称全局推动最优。
- 禁止“长物先让出返回位 → 小物取得推侧前进”后，穷尽 92 个状态仍无解。该条件不是最后获胜动作。
- 将同一条件平移一行映射到回环，禁止后无解；映射到旁路，禁止后仍有解，符合它允许其它策略的边界。两题均另有包含此条件的完整真实回放。
- 作者分析配置为 `maximumStates:100_000, maximumPlans:8, pushSlack:2, moveSlack:8`，发现多条宏操作顺序，不声明核心策略唯一。预定开路事件之后见证还剩 4 推；这是代理检查点，不是已观测的人类顿悟时刻。
- 删除两个冗余空格后，保留 12 个有效变异：删除两物件各可解、删三 Goal 各无解、封七初始空格各无解。起点、Goal 和初始物件占格不制造非法封墙；此范围不是所有地图变体的全覆盖。
- 物件删除的事件绕过会机械缺失实体，不能单独作为非冗余证明。补查存活任务：删除 C 后 A 无需先向左暂存即可完成；删除 A 后玩家无需推动即可到达 C 的左侧站位。两者确实参与共享空间，而非多加一个摆设。
- 合理误选另检验 `↑←`：当前状态无正常推动解，Undo 一次恢复可解，Restart 回到初态。它是测试场景，不是作者实际轨迹。
- 导航测试覆盖中性文案、三目标可见、通关不出现技巧总结、自由返回两难版，以及实验进度不污染两份正式课程进度。

测试过程先经历缺失关卡 / 无解的过窄版本 / 不必要空地 / 缺失实验室入口等红灯，再逐段修正。未将预算耗尽或无效布局当作证明，也没有放松难版规则。
