# 怎样反复利用并升级 Goal 数量与玩家占位认知？

把“Goal 可以多于真实 Block”“空 Goal 不妨碍胜利”“玩家站在 Goal 上不参与完成”从一次偶遇改造成完整认知弧。先允许玩家形成常见 Sokoban 假设，再用单变量关定界，然后把多余 Goal 变成目标分配、路线诱饵、可移动地形或 Rain 停点资源。

完成条件：每次回访都增加一个新的推理责任，而非重复同一个答案；反转关能排除偶然站位解释，综合关必须把空 Goal 的存在用于另一项必要技巧。
