# BD3 借隙：主动制造远端阻挡

LAB 50，`lab-bd3-controlled-entry`，指纹 `7f737953`。目标 D5 未校准。

## 与转隙的区别

初始右箱不堵出口。左箱运输线被入口实体占据，玩家必须先把右箱放在出口下方，使入口向下输入不再传送而变成推门。腾出左箱通路后，再利用已移动的入口返回右侧完成任务。

两边不再是独立任务：右箱的中间位置决定左边能否移动 Gate，移动后的 Gate 又决定如何返回右边。推门向下、再次进入向右；不宣称同方向许可恢复的循环必要。

## 可复核证据

`node scripts/audit-bd3-controlled-entry.mjs` 与该关 Vitest 测试，全部调用真实规则。

- 9×3，两箱初始未完成。31输入、5次实体推动。
- `RRDLURRDRDLUULLDRULDULLDRRLDRDL` 可回放获胜。
- 禁止‘移动过的箱子挡在出口落点导致入口推动’：穷尽1467状态无解。
- 禁止被这样推动的同一个 Gate 再次传送：穷尽1729状态无解。
- 公共事件序列“右箱推动→入口推动→入口传送”禁用无解。序列本身只是补充，因果另由前两项检验。
- 仅将入口初始从 (2,1) 移到 (2,2)，移离运输线后，无需主动造阻挡即可完成。
- 14个初始空闲地面格逐个封墙均无解。搜索设预算，耗尽不计无解。
