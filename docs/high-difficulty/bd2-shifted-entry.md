# BD2 转隙：先制造入射站位

## 定位与证据边界

- ID `lab-bd2-shifted-entry`，组 `batch-d-entry`，迁移候选。
- 前置为 BD1「双隙」和稳定 ID `lesson-44`（Gate 远端出口受阻）。
- 目标 D5，未校准；没有因步数、搜索状态量或设计标签自动获得难度评级。AI 中间验收与作者最终验收由共享验收记录分别管理。
- 主命题：利用任务物对出口的**初始阻挡**，把入口移至能取得所需入射方向的位置，再完成远端任务。
- 这不是原 BD2 完整卡要求的“主动制造阻挡→移动入口→撤销同一远端阻挡→同方向通过”。该更强任务仍 open，不以当前候选替代完成。

## 固定盘面与关联

```text
#..####
#E@#.X.
...#.B.
...#□##
```

7×4，E/X 互相配对，B 初始未完成。与「双隙」保留出口房的两次推侧任务和 Gate 配对关系；区别在入口左侧不再有站位。旧技巧“绕到入口左边，向右进入”不能直接执行，需要先移动入口，再应用原来的方向选择。

任务 Block 的初始位置同时阻挡向下的出口落点，因此从 E 上方向下输入会推 E，而非传送。玩家无需先移动 Block 来创造阻挡，也不需要移开它才有机会向右传送。可推性与入射站位建立有因果耦合，但不是完整的阻挡开关循环。

最自然的最近入口路线仍可尝试；继续向右推动箱子会形成不可恢复的边界死局。左房不是简单给出一条只管往前的走廊：一推 Gate 与两推 Gate 都可成功，允许合法局部方案差异。

## 真实规则审计

审计脚本直接载入生产源，所有后继交由 `move()`，状态键包含玩家、Block、两端 Gate 位置；不锁定 Gate 位置，不复制第二套推动规则。有限图预算 20000，耗尽输出未知，以下均已完成。状态数仅为已发现状态数。

| 实验 | 结果 |
| --- | --- |
| 基线 | `ULDDLDRDLURDLD`，14 输入，2 次 Gate 推动、2 次 Block 推动，128 状态 |
| 禁止所有 Gate 推动 | 无解，25 状态 |
| 禁止 E 向下推动 | 无解，50 状态 |
| 禁止从 E 向右穿越 | 无解，100 状态 |
| 禁止从 E 向左穿越 | 无解，89 状态 |
| 单推 Gate 替代 | `ULDRDDLLURDLURDLD`，17 输入，1 次 Gate 推动、2 次 Block 推动，真实回放胜利 |
| 错误最近入口方案 `LDR` | 无解，26 状态 |
| 只开放 (0,1)，禁止 Gate 推动 | `DLLURDLURDLD`，45 状态，可解且无 Gate 推动 |

四个禁止条件过滤领域事件，不禁止普通同方向行走。源 theorem 使用现有公共键 `event:gate-pushed:lab-bd2-shifted-entry-entry`，公共求解器也验证禁止后无解；精确方向与入口组合在独立有限图审计中验证，不扩建公共 API。

### 局部因果对照

执行 `UL` 后保持玩家、墙、Gate 和输入不变，只将 B 从 `(5,2)` 移到空闲 `(4,2)`：

- 原状态向下：发生 `gate-pushed`，不发生 `gate-traversed`。
- 变体向下：发生 `gate-traversed`，玩家到 `(5,2)`，无 Gate 推动。

这是一次合法静态状态的行为对照，不声称该变体是玩家已经通过原路线到达的状态，也不把它当作整关替代解。整体关系由开放 `(0,1)` 的单格解耦另行验证。

## 地面压缩

排除初始玩家、B、两 Gate 和 Goal 后，对其余 12 个地面逐格封墙，全部无解：

`(1,0)、(2,0)、(4,1)、(6,1)、(0,2)、(1,2)、(2,2)、(4,2)、(6,2)、(0,3)、(1,3)、(2,3)`。

上方入口格用于取得向下推动位置，下方空间提供移门后的绕行；出口落点和 Block 两侧承担原有换侧任务。该结果只证明此盘面的单地面封墙必要性，不声称墙体开放、所有物件变异及全体可能变体均已审计，也不能单凭全格必要判断题目有趣。
