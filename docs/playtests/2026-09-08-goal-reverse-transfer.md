## 证据强度与课程决定

作者明确说由转岸反过来学会涉岸，且涉岸更难。因此推荐顺序改为 **LAB 29 转岸 D6 → LAB 28 涉岸 D7**。编号是历史编号，不倒换稳定 ID 或盘面。转岸不再依赖涉岸，而保留共同基础前置；不强制所有玩家通过这条链。

这是“口述归因＋对应路线调整”的个体迁移证据，比只看演示后完成更强。但作者此前看过涉岸演示，仍可能存在记忆贡献，不能把这次归因当作控制实验，不能算陌生初见成功或长期掌握。样本数 0 指陌生测试人数，不是否认作者反馈。

品质认可、初见评级、复玩成功、技巧迁移分别记录。暂不添加第三道同技巧引导，也不提高标签或更改两张题目。

## 后续设计启示

1. 制作顺序不是教学顺序；后做的变式可以成为原题前置，须允许反向调整推荐边。
2. 好的桥梁应保留相互制约，让玩家自己改变计划；不要求逐步揭示原题路线。
3. 玩家可以通过非正式的空间认识完成迁移，不必先形成一句精确口诀。不要把“多推一格”设计成所有后题的固定答案。
4. 下一次只检验一个新的适用边界：某处空间必须暂时保留占位而不能一味清空。优先复用既有 [Rain 停止条件设计卡](../high-difficulty/e02-rain-variant.md)检查可行性，不为本次反馈另建平行评分标准。具体盘面、规则适配及必要性仍需验证；当前未新增这张地图。

已做第一项只读规则探针：保持转岸完整初态，仅把 weather 从 clear 改为 rain，清空原命题条件以免把旧证明要求误当胜利条件，用真实 `solveLevel`、20,000 状态预算检查。晴天有解（32 移动／9 推），雨天结果为 `proven-unsolved`，不是预算耗尽。因此不能直接换天气发布；下一次必须定位所缺的停止／推侧条件，再构造有解的候选。这个探针不证明雨天方向没有设计价值，也没有被加入课程。
