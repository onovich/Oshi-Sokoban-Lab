# 哪些技巧值得反复练习、迁移和组合？

从 60 个冻结基础关、P1–P10、公理—后果图和作者反馈中提取技巧节点，区分规则、技巧、整关策略与认知模型。实验室 Spike 原型不是已验收课程。当前总框架见[六条策略主线](../../../high-difficulty/design-guide.md#strategy-lines)，事件仅作为状态记录，不自动等于理解。

2026-09-04 增补：E06 已提供作者认可的 D4–6 组，但技巧可归纳性有限。图中另记“策略认识”，避免把“需要反复改变状态”直接计成一项已经清楚掌握的局部技巧。优先扩展更多可辨认方法，不只给三方交接增加长度。

关系同时有两层：技巧节点记录条件、意图、效果和适用边界；关卡节点记录稳定 ID、底板锚点与教学角色。关卡之间可以是巩固、定界／进阶、用途反转或部分组合，不用“同一完整解法”作为认亲条件。06／07 是只差返回格的对照，08 只保留其中一段关系，不能把三者合并成完全相同的技巧证明。

每次新机制进入课程策划，即检查已学技巧的迁移潜力；允许记录“不值得做”，不强制生成笛卡尔积地图。具体合同引用[两条扩展方向](../../../high-difficulty/design-guide.md#technique-growth)及[亲缘字段](../../../high-difficulty/experiment-briefs.md#teaching-and-lineage-contract)，不复制另一份标准。

完成条件：每个节点有前置、典型失误、最小练习、关系迁移、回访与必要组合；有关联底板时明确保留锚点和改变条件。作者评分与设计目标分开，不能预定机制难度上限。后续将有证据的节点映射到课程；纯换皮可记为巩固，但不算新技巧或进阶。文档字段就绪不等于全图或学习迁移已经验证。
