## 第一关：窄门

```text
G...#
##Ca#
#.@a.
#....
```

`a` 是已经覆盖 Goal 的两格竖物 A，`C` 是单格物，`G` 是 C 的目标。玩家必须先把 C 推到上排，再把看似已经完成的 A 向左移开；C 通过后，A 还必须回到原目标。

内部命题：**完成状态不是永久存放；已经完成的物件仍可暂时让路，只要保留把它归位的条件。**

这一关只建立“让位后还要归还”的动作因果，不引入另一个会抢占推侧的任务。标题和说明不出现“归还、取回、站位”等答案词。

## 第二关：近岸

```text
G...#
##Ca#
.G@a.
.B...
...##
```

在相同的 A／C 关系下增加单格物 B 与近处 Goal。玩家很容易先把 B 向上推入 Goal；这一步局部正确且不可逆，但 B 会占据 A 之后向右归位所需的唯一推侧，于是整关无解。

内部命题：**准备让一个物件暂时离位时，不只要看它的落点，还要提前保留把它取回所需的玩家站位；局部完成可能消耗这个位置。**

定界只改变一个因果变量：移除 `(1,1)` 的墙后，玩家可从北侧推动 A；即使仍然先完成 B，并禁止任何物件使用新增格，关卡重新可解。这说明死锁来自归还推侧被占，而不是笼统的“先做 B 一定错”。

## 第三关：再借庭

第三关复用原图，不降难、不改命题。它要求玩家把前两关的局部认识扩展到第二阶段：同一片空间需要再次借出，另一个长物的安排会决定玩家能否回到下一推侧。

期望的学习递进是：

- 窄门：亲手发现“完成物也可以先让位再归位”。
- 近岸：发现“归位需要保留一侧站位，近处完成可能抢走它”。
- 再借庭：在更多物件和第二次空间交接中，提前安排同一关系。

作者现已明确认可本链的循序渐进学习体验，支持其作为教学组合保留。具体是哪一处关系促成学习属于设计解释，仍可通过后续新图的解题过程进一步核对。机器可解性、作者组合认可和陌生玩家迁移分别取证。

## TDD 与机器证据

- 两张新图都由真实 `createGame()`／`move()` 搜索、逐步回放至胜利，没有第二套推动规则。
- 窄门禁掉 A 暂时左移后穷尽无解；当前最短移动见证包含 5 推，不把它另行宣称为全局最少推动数。
- 近岸的“先完成 B”合法发生，但从该状态穷尽无解；Restart 恢复原局。
- 近岸的单墙解耦对照在禁止物件使用新增格的条件下可解。
- 两关的命题事件均不可绕过；物件删除、Goal 删除及所有空格封墙变异没有未解释的冗余结果。
- 通用解法演示仍可用于卡关后的观察，但看完路线不计为独立解出，也不自动计为学会。
