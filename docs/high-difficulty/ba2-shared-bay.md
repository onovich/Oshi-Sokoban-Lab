# BA2 转廊 / LAB 42

2026-09-29。稳定 ID `lab-ba2-shared-bay`，批次 A 空间章节第二候选，目标 D5 未校准。全部真实物件初始未完成，不是预设残局。原理比折廊多一项交接：B 的目标位置先供玩家回收 A，之后才给 B 使用。

## 必要关系与对照

横条 A 初始在 Goal 上方；向下推动使其完成，但挡住离开初始区域的通路。必须再推下使其暂离完成位置，处理 B、绕到 A 下方回收。B 若过早进右下 Goal，会占据回推 A 所需站位。

不是只声称“需要把 A 推到 Goal”：证明条件为 A 离开 Goal → B 操作 → A 回归的序列。单个具体 B 暂存坐标不属于命题。

运行 `node scripts/audit-ba2.mjs` 可复核：

- 基础题 23 步、9 推，真实 move() 回放获胜。
- 禁止离开 Goal、禁止回归、禁止交接序列，分别报告穷尽无解。
- 可达错误前缀 `DDLLULDDLDRRR` 提前完成 B 后，A 不能回收；剩余状态无解。
- 反例前缀 `DDLLULDD` 把 B 先送到 (1,5)，仍可继续获胜。因此不强迫 B 一直停在 (1,3)。
- 只开放 (3,2) 一格，禁止 A 再离开 Goal 仍可 9 步、5 推获胜，新增格只被玩家使用。早期对照使 B 也从新格通过，混入运输变化，已弃用。
- 移除四个多余空格后，剩余 13 个可封普通空格逐格封闭均无解；这是当前地图的局部不可删性，不是全局最小性或人类难度证明。

两个开局推动较强制，可能低于 D5；不得因通过机器检查就认定难度成立。AI 只能进行中间初审，作者最终判断单独记录。
