# G09 截隙 — remote switching of a rain stopping point

Hash `a34bc7b8`; D7 design target, not measured difficulty. Unlike G04 (move the stopping object itself), the central relationship is moving the task Block at the far end so that a local Gate becomes a brake instead of a traversable passage. The Block still needs subsequent transport to its Goal.

Real move route `RDRRLDRURURLURDLLDLULDLDLURDRULLRU` wins, 759 discovered states. The necessary relation is a rain slide stopping immediately before a Gate whose projected remote destination is occupied by the moved task Block. Forbid every such event regardless of coordinate or Gate identity: 725 states, exhaustive no solution. Events in turns containing gate-traversed are explicitly excluded, so a teleport's final landing cannot accidentally masquerade as a local braking event. No traversal at all also exhausts, 79 states.

Add just wall(3,0): an independent static stopping constraint permits `RDRRLDRULLRRUDLLU` under the same dynamic-brake ban, 260 states. The new wall is a valid engine obstacle, not a modified rain rule. Twelve eligible floor closures: nine proven unsolved, three solved. (3,0) is the counterfactual. (0,1) and (0,3) create shorter different static stopping arrangements; keep them open to avoid replacing the dynamic task with a simpler prearranged layout. This is an explicit reason to retain open terrain, not an assertion that all open cells are movement-essential. Removing the only Block empties the victory condition, recorded but not used as meaningful necessity evidence.
