# BC2 借汀：暂缓完成，借来停靠

2026-09-29。候选 ID `lab-bc2-borrowed-stop`，目标 D5（未校准），接 BC1 折汀。机器审计不是 AI 初审或作者最终验收。

## 命题与玩家视图

```text
@.#□
..A.
#...
#□B.
##..
```

4×5 雨天，A/B 都是单格真实 Block，初始均未完成；图中字母仅用于设计说明，玩家看到普通白块。目标一在右上，一在 B 左侧。

**暂缓完成 A，用它提供 B 的推侧停点，用完后两件仍可正常完成。**

BC1 是箱子为自身提供停点；BC2 把关系迁移到另一任务物：看似离 Goal 很近的 A，应暂时保留工作位置。B 也不能简单左推到近目标，需要先离开该行，才能利用 A 的停靠位置。这不是将两个无关小题相连。

前置只有普通推动、雨天滑行及停点可改变站位。不给玩家“先别完成A”或路线提示。单格图形避免多格身份歧义；没有初始大半任务已完成的残局。

## 推理与替代方案边界

- 自然第一计划：A 右推后上推即可完成，B 看似只差向左一步。
- 问题：A 提前放到顶端，会失去 B 所需的停靠位置。真实可达前缀 `DRRDRU` 后穷尽83状态无解。
- 中间态：A 在 (3,1)，B 上移到 (2,2)，玩家可从 (3,3) 向上，借A停到 (3,2)，再向左推B。
- 用完后 A 和 B 谁先完成都可以，**不规定收尾顺序**。

两个有效收尾：

- `DRRDRDLURULRULURDD`：18 输入、5 推，A 先完成。
- `DRRDRDLURULULURDDRU`：B 先完成，再完成 A。

后者反驳了“必须先释放/完成 A，才能完成 B”的过强设计主张。也不能用“禁止支持后 A 再移动会无解”证明高阶交接——A 本身还要完成，这可能只是任务要求。BC2 是可恢复临时停靠练习，真正的二次资源交接留待 BC3，不为难度目标编造依赖。

## 自动验收

运行 `node scripts/audit-bc2.mjs`。所有搜索边由真实 `move()` 生成，状态是两物件位置、玩家位置、一个即时停靠标记；方向输入若没移动不扩图。16,000状态预算耗尽记未知并使审计失败。

| 检查 | 结果 |
| --- | --- |
| 原图真实求解器及独立位置图回放 | solved；18输入5推；位置图272状态内找到胜利 |
| 禁被 A 挡停后的紧接动作推动 B（含一格接近） | 252状态穷尽无解 |
| 禁 B 从 (2,3) 上移至 (2,2) 的事件地标 | proven-unsolved；仅作必要地标，不代替停靠关系证明 |
| 提前完成 A 的真实可达前缀 | 83状态穷尽无解 |
| A先完/B先完两条路线 | 均完整回放获胜 |
| 局部移除 A 的反事实 | 同一次向上从停在(3,2)变为滑到(3,0)，失去立即左推B的站位 |
| 仅加墙 (3,4)，同时禁A支撑B停靠 | 8输入 `DRRDRUDL` 可解；52状态内找到胜利 |

“停靠”标记只覆盖下一次实际操作，不是A曾经挡过玩家后任意一次推B都计入。下一步行走或推动其它物件会清除；不能用宽泛历史关联冒充因果。

全10个合法普通地面逐格封墙：9个导致无解，唯一(3,4)封墙提供替代刹车并解除命题。这证明局部封格审计，不证明全局最小地图。已删除最初候选的左侧整列及无意义左下区域，没有为延长路线保留空间。两个 Block 都是任务且承担关系；删除A为上述局部因果干预，不拿空任务胜利充当删除证明。
