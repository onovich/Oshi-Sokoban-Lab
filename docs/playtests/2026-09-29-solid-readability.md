# 多格物件接缝修复

## 发现与边界

根代理在复廊初始盘面观察到：同一三格竖块的第二、三格之间出现细缝。现有轮廓代码已经正确排除了内部边，不是盘面被拆成两个物体，而是独立 SVG 格片在非整数像素尺寸下的栅格化接缝。

本次只修改表现层，不修改地图、稳定 ID、命题、碰撞或任何机制。对同一物件的内部接边补半像素底色，并连续绘制外轮廓；与别的物件相邻的外边不扩张。格子仍全部填满，不引入间隔。

网格的无障碍描述增加物件序号、总格数与当前占格坐标；编号不写进画面，也不是关卡设计元数据。

## 验证

- Board 公共渲染测试：先验证同一物件各格具有相同形状描述，原实现失败，修复后通过。
- Chrome 实际页面：复廊初始盘面在 320、768、1024、1440 宽度下检查，竖块内部没有原来的横向细缝；独立方块仍有独立轮廓。视口恢复默认。
- 完整自动验证与构建由 Git 工作流执行。
