# Oshi 难度 1–10 技巧掌握路线图

状态：实施中——课程架构、分析器 v2 与 P1–P10 候选关已落地；真人校准闸门开启
建立日期：2026-09-03  
本地跟踪方式：本目录中的 Markdown tickets

## Destination

在不改写已核验规则、不替换作者已验收基础课程的前提下，形成一份可实现、可求解审计、可盲测校准的进阶课程方案：它覆盖 1–10 / 10 的真实难度谱，让玩家对关键技巧经历“种下—巩固—施压—打破—迁移—综合”，并能在高难关中主动组合这些技巧，而不是只在第一次见到机制时偶然使用一次。

到达终点时应同时具备：

- 一套由真人数据校准的 1–10 难度量表，而非凭作者或求解器主观打分。
- 一份玩家信念台账，明确每条认知在哪些关卡被种下、巩固、打破和迁移。
- 一张技巧—前置—组合图，区分规则知识、局部技巧和跨机制策略。
- 至少一条从基础到 10 / 10 的完整示范关卡弧，并通过命题必要性、可解性、紧凑性和盲测。
- 一套能扩展到其它技巧族、又不会让高难关卡死全课程的导航结构。

## Notes

旧课程没有被推倒重来：已由作者完整游玩并验收的 60 关现已成为 `accepted-foundation-v1`，并由冻结指纹保护；原 19–21 已改成 `lab-spike-*` 语义 ID，只在开发实验室保留，不计正式进度。`mastery-v2` 以固定五幕 120 槽蓝图穿插冻结关和 60 个新增关，目前 60 个冻结关与 P1–P10 共 70 关可玩。

已验收基础关采用“冻结并穿插”的演进方式：旧盘面、内部命题和关键解法不因新认知弧而改写；需要长期铺垫时，在原有组之间插入新桥接关。关卡的稳定内部 ID 不等于显示序号，未来课程重排只改变目录位置，不修改旧 ID 或完成记录。

“认知误导”采用以下严格含义：玩家从多次真实、稳定的结果中形成一个当时有用但不完整的模型；后续关卡保持规则不变，只改变问题结构，使完整解释比旧模型更有预测力。任何依赖隐藏状态、临时例外、含混图标或错误文案的 surprise 都不算合格。

首批需要纳入台账的候选信念包括：

- “所有可见 Goal 都必须填满”——先通过常见布局自然形成，再用多 Goal / 少 Block 的完整可玩关卡定界。
- “玩家站进 Goal 也参与胜利”——先允许空间关系造成这种过度归因，再用玩家明确不在 Goal 上的等价解反证。
- “Spike 是必须避开的销毁障碍”——用多次非必要接触、损失进度和明确销毁演出巩固；之后才用 origin 回位解决表面无解局面。
- “origin 只是出生点／恢复点”——先强化静态残影和复生，再揭示它是可管理、可阻塞的远程目的地。
- “Goal 只是终点”——之后迁移到可移动物件、通路和 Rain 刹车点。
- “Gate 只是通道”——之后通过出口占用和端点移动把它转化为受远端状态控制的物件／拓扑工具。

难度升级的主要来源应是：必须保留的推侧、不可交换的次序、暂时牺牲完成状态、稀缺目标分配、origin / 出口占用、远端条件、状态循环和两至三项技巧之间的资源冲突。地图面积、搬运长度、不可读动画和高试错成本不能被当作难度。

## Decisions so far

- 保留已验收基础课程，并把它明确标为 1–3 / 10 的规则识字层。
- 不向已验收盘面硬塞 Spike 或其它机关；新增认知铺垫使用独立桥接关，并以冻结清单保护旧盘面、命题与关键求解指标。
- 新增进阶课程，不通过把基础盘面机械加长来伪造 4–10 / 10。
- 三关组继续承担建立、定界和首次推演；技巧掌握弧可以跨多个三关组，也可以在其它机制族中穿插巩固。
- 每个关键技巧至少要出现于变式练习、反向验证、跨布局迁移、必要组合和高难综合中。
- Spike 避让直觉需要早于“利用回位”长期铺垫；当前 19–21 仅视为可迭代原型，不视为已经解决该设计问题。
- Spike 的铺垫必须跨越其它机制族与时间间隔：前期只作为辅助障碍，后期才出现以回位为核心的专门 Spike 族；当前 19–21 的编号与相邻关系不是正式路线约束。
- 辅助 Spike 关要求零重置正解，并以“删除 Spike 会产生捷径／绕过”证明它是有效障碍；揭示关则反过来要求重置事件不可绕过。
- 先用销毁碎片、接触闪光和 origin 弹性重生建立可读因果，但动画不能成为规则唯一证据。
- 高难关仍须静态可推测；Path Spike 暂不进入主课程。
- 难度 8–10 必须由已学规则的二阶／三阶后果产生，并保留短顿悟尾巴。
- 求解器证明可解和命题必要；真人盲测校准理解过程与难度，两者不能互相替代。
- `mastery-v2` 固定为 120 个正式关：60 个冻结基础关与 60 个新增关；新增配额为 P12、H8、G4、I6、R6、T6、S6、C6、U6。
- 五幕规模固定为 30 / 30 / 29 / 24 / 7；H1–H8 全部位于第 70 槽之前，已验收 Spike 回位两组占第 70–75 槽。
- 分层完成固定为：全部 D1–6 目标槽取得基础结业，六个主要 D8 终点中任意三个取得主线结局，全部 120 关取得 100%；D9–10 可暂时离开。
- 第一条生产样板弧 P1–P10 已完成机器验收，目标覆盖 D3–8；这些数字仍是 `design-target`，不是实测难度。

## Open evidence gates

- P1–P2 各至少需要 3 名目标玩家，P3–P9 各至少 5 名，P10 至少 8 名熟悉逻辑解谜的玩家；在此之前不把目标难度写成实测难度。
- 只有 P1–P6 的难度曲线与技巧迁移成立后，才把 P7–P10 视为有效进阶；P11–P12 继续等待该证据，不能为补齐蓝图而提前定稿。
- 仍需用口述假设、尝试路径、重开／Undo、顿悟后推动和歧义记录，区分“沿正确问题思考很久”与“表达不清导致卡住”。
- H1–H8 的固定数量是课程设计目标，不自动证明误导自然；顺序盲测必须验证至少 4/5 玩家在第 70 槽前主动避刺，并把回位理解为损失／恢复。
- P12 通过作者验收与专家盲测，是开始横向生产其余 H/G/I/R/T/S/C/U 正式候选关的闸门。

## Out of scope

- 为提高难度创造尚未由原版或作者裁定支持的新规则。
- 把动态 Path Spike 纳入当前主课程。
- 立即把 19–21 标为已验收关卡。
- 用更大地图、更多无关物件、长距离搬运或隐藏信息填补高难档。
- 在缺少真人数据时宣称某关已经达到 8、9 或 10 / 10。
