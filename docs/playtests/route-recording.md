# 本地完整路线记录

页面底部“导出完整路线”下载 `oshi-routes.json`，可作为聊天附件提供。记录自动在当前浏览器、当前站点的 localStorage 保存，不上传、不录屏。按作者最新要求，新操作记录毫秒级时间戳；localhost 与 127.0.0.1 的记录互不相通。

开始操作时建立新局，换关／重新进入关卡后分局；刷新保留旧记录，新的操作另起一局。导出包含当前页面已载入及保存合并过的各局记录，不只是当前最终路线。浏览器清理站点数据会删除本地记录，请及时导出。

## 内容

- 格式版本 `version: 1`、随机局 ID、课程与区域、完整关卡定义及初始盘面。完整定义本身是本局的地图版本快照，不依赖后来同 ID 的地图是否修改。
- 按顺序记录方向、引擎是否接受移动、Undo、Restart。撤销不删除之前的尝试；没有历史可撤销的键盘 Undo 也会留下记录。
- 尖刺演出锁定时收到的方向键记为 `input-locked`，与碰墙的 `blocked` 分开。浏览器未送达游戏的输入（如选关菜单内方向键、禁用按钮）不计入。
- 手动与演示使用不同 `source`。演示进入、实际播放／单步到达的方向、重播、退出分别记录；不把尚未播放的整条解法当作已观看。退出记录恢复的玩家局面。
- 每条附操作后的逻辑盘面，包含物件原位、Path 状态和胜负；省略 Undo 历史的重复嵌套及剩余秒数。分析者可按快照逐步重现，不必假设未来版本规则完全一致。此版本未增加网页中的记录导入／回放播放器。

## 操作时间与解释边界

每条新操作附 `timestampMs`，为记录操作时的 UTC Unix 毫秒数（浏览器 `Date.now()`）。移动、阻挡、输入锁、撤销、重启、演示事件均计时；沿用格式版本 1，旧条目缺失此字段代表未知，不能补造为 0 或导出时刻。

同局相邻、有时间戳条目相减可得操作间隔。它包含动画、走神、离开或切换页面，不直接标注为思考／犹豫；未记录前后台状态。演示与手动仍按 source 分析，跨演示、重启或 session 的间隔不当作同一盘面的推理时间。系统时钟可能被调整，负间隔或异常长间隔应标记待核对，不静默修正。条目顺序仍以数组为准。

当前 session 从首次输入开始，因此无法测量开局至第一次输入的观察时间，也无法测量最后操作至导出的停留。时间戳帮助定位值得回看的间隔，不代表已经实现页面内统计面板或可靠的认知诊断。必要时结合路线询问“当时想先完成什么”。观看演示不等于独立解出或学会。

## 保存边界

确认使用页面内“确认清除／取消清除”按钮，不依赖浏览器原生 `confirm` 弹窗。2026-09-09 作者报告点击无反馈；测试复现原生确认被取消／抑制时静默退出的路径，故移除这项宿主弹窗依赖。回归测试覆盖不调用原生确认、取消保留数据、确认后计数归零及从原局面继续记录。测试未删除作者实际路线。

“导出完整路线”旁的“清除路线数据”需要确认后才清空当前站点全部路线（包括其他关卡的尝试）。不改变当前棋局、Undo 历史、通关进度或下载目录的文件；清除不可撤销，建议先导出。下一次操作从当前局面另起记录。演示过程中暂不可清除。存储写入失败时保留原记录并提示失败。

清除用可选的 `generation` 随机标记隔离旧记录，不改变格式版本。同源旧标签页在后续读取／记录时识别清除标记，不把旧路线重新合并回来；新操作以该页清除后继续操作前的局面为起点。不同站点来源仍需分别清除。

保存失败会显示警告，新记录仍在内存可导出；无法读取的旧数据不会直接覆盖。浏览器存储不是无限的，也不是服务器备份。普通多标签页交替写入会合并已有局；localStorage 没有跨页事务，严格同时写入不提供并发保证，建议只在一个标签页试玩。
