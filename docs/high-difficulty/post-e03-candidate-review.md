# E03 之后：先检验计划冲突，再生产教学变式

状态：本文件记录上一轮初筛，当时没有新增试玩关。后续合庭机器通过，但作者未解出且看演示仍未掌握，现制作[辅助学习候选](e04-teaching.md)。本页的 14 个拒绝探针仍不发布。LAB 14–16 的旧盘面、ID 和完成记录不变。

## 已修正的判断

西庭的远目标没有进入作者的实际考虑。它是机器可以区分的新终局，但不是玩家需要权衡的另一项计划。下一候选不能以“换了一个 Goal 留空”作为充分教学证据。

新的局部计划应能获得真实进展，而其代价来自另一项任务需要的推侧、暂存区或返回路径。吸引力仍要由玩家的第一计划验证，AI 不能通过命名“诱饵”证明玩家会考虑它。

## 本轮可复现筛选

沿用真实 `move()` 和既有空间 oracle，不改规则、不扩建求解器。针对 E04 的一项特定假设进行初筛：**非初始完成的长物必须经历完成后撤回，才能协调另一任务**。这只是本次候选的门槛，不是所有好谜题或 D5 的通用公式。

## 下一地图的制作起点

停止继续扫描上述底板的目标位置。改为从**共享暂存区的交接**构造几何：

1. 两个物件各自有可执行的局部准备方案，而不是一个远处、明显无用的 Goal。
2. 完成前一项局部准备会消耗后一项的操作条件；尚未直接进入不可挽救角落时，玩家能检查出冲突。
3. 存在可恢复的中间态，让两项任务交错推进；不靠 Undo 充当解法动作。
4. 必须测试两种整件优先策略，而非只禁止作者指定的一条方向序列。
5. 增加独立暂存区或到达路径后，相应交接要求应解除，证明冲突来源。
6. 只有完整地图通过上述检查、可回放与变异审查后，才制作简化教学题并进入试玩。

这是下一候选的制作合同，不是尚未存在地图的可解性声明。难度继续由作者和陌生玩家分别取证，不为填补难度等级调整标签。
