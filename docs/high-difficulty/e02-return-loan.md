## 内部设计说明（含解题关系）

### 盘面与亲缘

```text
GGG.#
#GCA#
#G@A.
#.BB.
#....
```

左上角为 `(0,0)`。A 为两格竖物，B 为两格横物，C 为单格真实物件；G 为静态通配 Goal，均不可旋转。5×5 外框、19 格地板、三个物件占五格，五个 Goal 初始全部未被遮挡。

这是 E02 的同底板空间迁移：保留双长物方向、右上墙角、南侧绕行区和中部瓶颈；改变物件初态与目标安排，增加一个争用上侧通路的单格任务，并删除不再必要的 `(0,1)` 地板。并非 09 的单变量对照，也不是仅增加同一技巧的次数。真正的单变量解耦另在下文测试中构造。

### 总命题及工作性技巧

**第一次把 A 借放在中部，为 C 打开上侧通路时，必须保留南侧返回口。随后把 A 归还到右侧，才有条件从下方取回 B；B 离开以后，A 才能第二次使用中部并完成。**

前置来自 E02 的可恢复暂存和推侧保留。内部可归纳方法是：物件不但要留在能再次推动的位置，玩家也必须保有到达下一推侧的路线。先占据“离目标更近”的格子，可能使另一阶段没有返回办法。这是设计者假设，尚无作者对本图的技巧描述。

| 阶段 | 空间条件 | 对后续的影响 |
| --- | --- | --- |
| C 移到上排 | C 暂占 `(2,0)`，释放 A 的左移落点 | C 自己仍不能继续向左，因为玩家尚无右侧接近路。 |
| 第一次借用中部 | A 从 `(3,1)` 到 `(2,1)`，腾出右上通路 | 玩家得以从右推 C；此时 B 应仍在 `(2,3)`，为南侧回程保留 `(1,3)`。 |
| 归还右侧位置 | A 从 `(2,1)` 回到 `(3,1)`，让中部落点重新可用 | 玩家通过保留的左下返回口到达 B 的操作侧；不是把 A 永久塞在临时位置。 |
| 第二次借用中部 | B 左移并上行之后，A 再次向左 | 此次 A 可以完成，已不必为 B 保留那条路线。 |

C 不必在 A 归还右侧之前已经推到 `(0,0)`：推到 `(1,0)` 后先归还 A、再完成 C 也有解。证明条件保留这类合法换序，不锁死最短见证的全部动作。

### 有意义的错误计划与有效对照

错误计划：先把 C 移到上排，把 B 提前向左推近目标，再借 A 的中部位置去处理 C。此计划能实际完成 C；不是入口立即走不通。可是将 A 归还右侧以后，B 虽然上方两格全空，玩家却到不了 B 下方，无法取回它。这里区分的是“落点空着”与“推侧可达”，不是尖刺、边界深停或隐藏规则。

对照只开放西侧 `(0,2),(0,3),(0,4)` 三格，保留同一初态、形状、Goal 与规则。沿同样的错误前缀走到同一状态，然后：

- 约束所有物件不得进入新增格，它们只供玩家行走。
- 约束 B 始终保持 `x=1`，不准把提前左移撤回，避免把恢复误判为另一条箱子运输路线。
- 对照仍可完成，最终见证为 A `(1,1)`、B `(1,0)`、C `(0,0)`，与主版见证分配一致。
- 单独重新封闭三格中的任何一格，受上述约束的对照再次穷尽无解。

所以这项对照支持：提前占用 B 的左侧位置之所以会坏事，确实依赖缺少玩家返回路。它不证明对照对人一定更简单，也不加入可见实验室列表，以免作者在主版试玩前被提示。无约束对照可以产生其它摆法；未用那些摆法作这个因果证据。

## 机器证据与边界

实现：[关卡](../../src/levels/lab/e02-return-loan.ts)、[命题与对照测试](../../src/levels/lab/e02-return-loan.test.ts)、[实验室入口回放](../../src/App.lab-learning.test.tsx)。

- 无剪枝真实规则搜索与现有分析器均能回放获胜；最佳移动见证为 38 步／11 推，比 E02 主版的 40 步／12 推更短，难度目标来自关系变化而非搬运量。
- 禁止“借出 A 后，仍能从西侧归还 A，并通过保留通路走到下侧”的真实状态关系后穷尽无解。步行可达性和推动许可均使用 `move()`，不是另一套碰撞模型。
- 有序借用／归还／移动 B 及 A 两次借用的类型化条件分别不可绕过。计数只是补充，不独自充当技巧证明。
- 错误的提前左推后无解；Undo 可撤回这一步，Restart 恢复初态。完成 C 后的失误状态仍无解，其 B 的上方落点未被占用，但无法取得推侧。
- 删除 A 后，提前左移 B 的存活任务可以完成；删除 B 或 C 后，仍存在的 A 不再需要中途向右归还。不是只用引用已删除实体的谓词证明物件必要。
- 16 项有效变异：三件物体删除分别解除相关依赖；五个 Goal 删除、八个空格封墙均无解。没有未解释冗余、无效变体或预算耗尽被计为证明。初态已占格不做非法封墙。
- 有限窗口采用 `maximumStates:200_000, maximumPlans:8, pushSlack:2, moveSlack:8`。C 的完成与 A 归还允许换序；即使窗口只展示一种宏计划，也不宣称全成本策略唯一。
- 将 A 归还右侧是因果准备检查点，最佳见证之后还有 6 推。它不是已观测到的人类最后顿悟；如果玩家更早想清楚，执行尾巴仍须另记，不能后移检查点伪装合格。
