# 当前模型对照发现

对照依据：原始 01-faceted.png、construction-study-v1.png，以及 Blender 无头渲染的 model-v3-front / side / back.png。三张模型图使用相同正交比例与姿态。

1. 肩甲像包裹整个上臂顶部的厚壳，原画更接近附着于关节外侧的薄片，黑色肩球应更可读。
2. 前胸装甲像整体凸板，原画有中线分件、斜向下缘和更清楚的内部黑色结构。
3. 骨盆外壳和左右盖板偏方，原画的中央护片与侧面挂件更收窄、倾斜，髋关节留空更明显。
4. 侧视下，头盔与躯干的折线过于直立、均匀，需等待合格侧视原画确认前后厚度。
5. 原画磨损分布围绕边缘、板缝和固定件；现有顶点色变化较机械，不应通过更多浮动三角片补救。

以上用于下一轮建模，不作为新原画修改原始角色的理由。最终尺寸以一致的三视图和三维运动校验共同确定。
