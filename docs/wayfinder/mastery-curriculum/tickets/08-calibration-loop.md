# 如何证明认知弧公平且难度确实上升？

扩展现有盲测协议，记录玩家进入关卡前的预测、首个假设、何时调用已学技巧、错误是否可解释、提示需求、顿悟时刻和顿悟后推动数。把“被误导”区分为合理过度概括与表达失败。

完成条件：每个难度锚点有足够样本；Spike 反转前多数玩家会主动避刺，反转后能用完整规则预测 origin 占用等边界；若卡顿来自图标、动画或隐藏状态，关卡退回而不能被计作高难。
