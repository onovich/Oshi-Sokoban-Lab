# BB1 回埠：先借工作位置，再恢复落点

2026-09-29。稳定 ID `lab-bb1-goal-workspace`，规范化指纹 `eed647f4`。Goal 章节练习候选；目标 D4 未经校准，不宣称 D5 或作者已验收。

## 核心关系与定位

Goal 起初位于 Block 下方，看上去已经是合适的最终落点。但玩家在右侧，不能直接取得向下推动 Block 的站位。把 Goal 向左挪一格仍不够：它占着通往上侧的站位。必须继续移到工作位置，绕至它的回收侧，再把 Goal 送回最终落点，最后完成 Block。

这是一道小型完整练习，不是高难综合：只有一个未完成 Block，没有预先完成的任务物；Block 确实只在最后一步推动。主要判断在 Goal 的临时用途与回收，而非多物件调度。添加第二 Block 的探索只增加机械操作，已舍弃。

与涉岸/转岸不同：本题不要求撤回已完成箱子，不承担两个箱子之间的完成顺序冲突，也没有复制旧关的一段残局。它使用独立小盘面，把 Goal 的工作位置与最终位置区别单独放大。不能据此宣称能教会旧高难关。

自然错误方案：先只挪 Goal 一格，直接向上推动眼前 Block。`LU` 后 Block 到顶边，无法取回向下推侧；不是缺少未知规则，而是可见的边界限制。

## 机器证据

`node scripts/audit-bb1.mjs` 直接加载生产源图，不复制 Temp 的旧双块原型。所有转移均调用真实 `move()`，因此 Goal 能推则推、受阻可穿等合法替代路线都参与枚举。普通步行 BFS 上限 22,000 状态；本次没有预算耗尽。

| 检查 | 结果 |
| --- | --- |
| 原图 | 可回放获胜，12 输入、5 次物件推动；BFS 186 状态 |
| 禁止 Goal 向任一轴的两个相反方向移动 | 穷尽 121 状态无解 |
| 禁止 Goal 到达 `x<2` 的工作区 | 穷尽 45 状态无解 |
| 分别禁止声明中的越位/回收事件 | `solveLevel()` 均证明无解 |
| 错误前缀 `LU` | 穷尽 63 状态无解 |
| 只开放 `(4,3)` 侧路，禁止越位 | 8 输入可解，69 状态 |
| 相同对照，禁止方向反转 | 8 输入可解，127 状态 |
| 相同对照，同时禁止越位与反转 | 8 输入可解，69 状态 |
| 相同对照，禁止一切 `goal-pushed` | 仍可解，Goal 可以完全不移动 |

两条同长真实获胜路线都保留：

- `LLULDLRRUURD`：一次穿过受阻 Goal。
- `LLULLDRRUURD`：从左侧绕行，零次穿过 Goal。

因此 **Goal 穿过不是本题必要命题**。不能用示范路线含一次穿过，就声称本题强制教授推/穿切换。

对照路线：`DLULUURD`，Goal 始终可留在 `(3,2)`。真正取消的是取得上侧站位的共享约束，不是替换运动规则。

## 地面压缩与保留元素

在真正单 Block、无静态 Goal 的最终版逐格审计，而非复用早期双块数据：

- 删除 `(0,0)` 旧空口袋；它对主关系、对照与错误方案均无必要用途。
- 9 个普通地面格逐一封墙，7 个变体无解。
- `(0,1)` 保留同长度普通绕行方案。删除它会强制穿 Goal，这不是本题希望额外要求的技巧。
- `(3,3)` 保留可见的下侧空间及独立侧路连接：删去后，仅开放 `(4,3)` 无法再解耦。它没有伪装成原图可解性的必要格。

这两处在 `readabilityElements` 中明确标注；不宣称整个地图为全局最小，也不以“最短步数不变”一律删除合理路径。
