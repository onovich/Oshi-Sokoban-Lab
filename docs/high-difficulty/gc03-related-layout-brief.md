# GC03：Goal 空间协调的同底板迁移实验

状态：原任务书保留；后续已有 [GC03-V 转岸 / LAB 29](gc03-goal-handoff.md) 可玩收敛变体，稳定 ID `lab-gc03-goal-handoff`。它检验 Goal 返回位置与箱子提前下运的冲突，不冒称下文旧角落强命题已实现。依据为[涉岸作者反馈](../playtests/2026-09-08-author-gc01.md)，不是外部作者方法论的新结论。

实施进展：[首轮 392 份局部布局探针](gc03-probe-review.md)未放行候选：已证旧准备失效的变体，分别存在永久收尾或不移动 Goal 的绕过；4 份预算耗尽保持未知。下一轮改查初始运输关系，不向实验室填充弱题。

## 要回答的问题

在已会局部规则并看过涉岸部分演示后，玩家能否在相似结构中重新判断“Goal 应放哪里、箱子何时暂时离开目标”，而不是记住向左下搬 Goal 的方向？本实验不承担让所有玩家学会涉岸的职责，也不预设必须比 D7 更难。

唯一总命题假设：**Goal 的落点必须由尚未完成任务需要的返回通路决定，不能把上一题的安全位置当作通用答案。** 两个局部安排应相互限制；不是先搬 Goal 再完成两个互不相关的小题。

## 保留什么，改变什么

- 保留可辨认骨架：两只单格真实箱、一个移动 Goal、一个固定 Goal、狭窄交接区与外围回程。普通推动和 Goal 推／穿为全部规则，不加入新机制。
- 优先单一因果变化：改变后续任务所需回程的接入位置，使原来安全的 Goal 暂存／最终落点不再安全。几何实现可能涉及多格，必须列清哪些改动共同实现这一变量，不能把多格变化伪称逐格单变量对照。
- 不做整图镜像或旋转；若解法只是方向替换或多绕一圈，退回。玩家应辨认亲缘关系，但需要改变一个中间子目标。
- 不指定最终坐标或路线以迁就预想。若无法在紧凑布局中保留同底板与真实冲突，记录失败，不能用全新大图冒称同底板实验。

## 原型应呈现的因果关系

1. 自然第一计划：将 Goal 放到“看起来像涉岸安全角落”的位置，再分别完成箱子。
2. 地图反证：该位置会夺走另一箱后续需要的推侧或返回通路；错误应可从静态占格关系推断，而非图标或动画歧义。
3. 必要中间状态：尚未收尾的箱子与尚未最终落位的 Goal 同时保留可恢复性；只顾其中一个会使另一任务失去条件。
4. 新计划：依据末段通路倒推 Goal 落点及暂时完成的撤回时机。不能只在开局识别一次角落后一路机械执行。

这些是待证假设，不是已经实现的关卡性质。不要求所有局部方案都唯一，也不靠扩大状态数证明推理更深。

## 制作与淘汰合同

沿用已约定的真实 `move()`、求解器和回放接口，逐个完成测试 → 最小地图 → 证明，不复制第二套规则：

- 初始状态有可回放的合法胜利路线。
- 将“沿用旧安全落点”的合理错误方案实际走到检查点；标明真死局还是仍可恢复但需改计划。两者都不能凭印象命名。
- 定义具体空间关系的禁止条件，验证核心准备不可绕过；禁用所有 Goal 移动只能证明机制必要，不能证明迁移命题。
- 解耦对照提供独立返回通路，应解除所宣称的落点冲突。对照若只缩短行走而未改变计划，不算通过。
- 保持原涉岸原件；候选使用新 ID。检查替代目标分配、边界钉住 Goal、提前永久完成任一箱、无视移动 Goal 等绕解。
- 进行实体删除与封墙变异；保留合理错误方案的元素需写用途。不以最短步数相同自动判冗余。预算耗尽、无效变体为未知。
- 若两个安排可以独立完成、旧路线直接奏效、仅重复已知动作，或共享冲突被简化掉，淘汰或降为练习，不抬高难度标签。

本轮最多发布一个通过机器审计的候选，不同时追加 GC02 与多个提示关。未通过就保留失败记录，不为了让用户有新题而填充。

## 试玩与生产决策

前置为基础 Goal 推／穿规则与一条空间回程学习线，可任意顺序完成；涉岸作为亲缘参照，不强制用户重看演示。选关可标明与涉岸相关，但不展示内部命题、正确落点或新路线。

正常记录路线；结束后才问：是否联想到涉岸、第一次安排为何改变、能否指出哪个后续任务要求了这次改变。接受通过推敲形成答案，不用解题速度或能否说术语单独判掌握。

- 若独立重组计划且能解释关系：支持此作者的迁移，仍不是陌生群体教学证明。
- 若独立完成但没有相关认识：可能是好练习，不能宣称迁移成功。
- 若未完成但认可挑战：保留挑战价值；定位盲区，不能自动追加手把手前置。
- 若表达歧义导致卡住：修表现，不把它归入合理难度。

先完成这一对“原件—变式”的证据再决定回到 GC02 多次交接，或转向其他机制。正式收录与批量生产继续服从[统一试玩协议](../playtest-protocol.md)，不因单个 D7 作者评价跳过校准。
