# H1 迂径：避刺背景下的运输次序

早期铺垫候选 LAB52，稳定ID `lab-h1-detour`，盘面哈希 `0fdb0e02`，独立于中高阶12关批次计数。仅开发实验室，不改正式目录、既有盘面或正式 Spike 揭示位置。目标D3，未校准。玩家标题不提尖刺或回位。

```text
#.B□.
.....
@A.^□
#..##
```

主任务是推侧与收尾次序。A 看起来只需沿直线向右，但刺让这条路线损失已经前移的布置。绕上方运送需要上边通道；B 的近目标恰好占据该通道，必须延后收尾。刺是改变运输条件的辅助元素，而非唯一教学对象。

## 可证伪条件

- 完整规则与禁止 object-reset/death-reset 都有16输入、6推动的最优解。允许重置不提供更低成本正解。早期人工数路线误报15，正式双成本测试与求解器已纠正为16，不是地图发生变化。
- 去掉刺后为8输入、4推动，且可以先完成B再完成A；保留刺时禁止“A已完成而B尚未完成”状态，穷尽无解。
- 直接 `RR` 能真正触刺，A回到出生点，失去前移布置。并不声称永久消失，也不隐藏出生标记。
- 不以所有解都会发生的最终完成动作充当主命题证明；另检验中途离开直推路线、绕运和收尾关系。
- `(0,1)` 是可选格：允许玩家从开局便接近B的诱人近目标，保留完整的合理错误计划。其他普通空格逐格封墙核验。

## 证据边界与后续编排

这张题只能检查一次避险运输体验，不能独自证明长期避刺信念。未来应与非Spike章节交错，并继续制作不同主技巧的桥接题；不能紧接归隙作为线性推荐，也不能让体验过回位揭示的AI替代未见揭示的顺序盲测。
