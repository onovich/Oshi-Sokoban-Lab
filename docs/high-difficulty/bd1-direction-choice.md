# BD1 双隙：两次入射方向与推侧迁移

## 状态与范围

- 稳定 ID：`lab-bd1-direction-choice`；组 `batch-d-entry`，迁移候选。
- 目标 D4，尚未校准；机器证明不等于 AI 试玩通过，更不等于作者最终验收。
- 前置 `lesson-42`（Gate 方向携带远端推侧）。若试玩者此前不知道 Gate 规则，其反馈只能支持规则发现/可用性初筛，不能证明技巧迁移。
- 本卡不是 BD2 原计划的主动制造远端阻挡、推动入口、再撤销阻挡；那张完整设计卡仍未实现。

## 固定盘面

```text
...####
.E@#.X.
...#.B.
####□#.
```

7×4；E 与 X 互相配对。B 初始未完成。仅普通 Block、静态 Goal 与既有 Gate 规则。

总命题：箱子转向后需要另一推侧；返回入口选择另一入射方向，而非坚持最近的入口走法。与基础方向课相比，不是把同一方向重复推动，而是第一次推箱后改变所需推侧，再通过入口重新安排方向。暂不声称玩家一定发现了这层关系。

合理第一计划是从紧邻玩家的入口向左进入。该试验可以原路返回；若继续把箱子向右推，会把它推到无法取回的右边界。失败由完整可见的几何解释，无额外规则或隐藏限制。

## 实际源证明

`scripts/audit-bd1.mjs` 直接载入生产关卡，通过真实 `move()` 枚举有限状态；状态包含玩家、Block 与两端 Gate 位置，不冻结 Gate 的合法移动。预算耗尽单列未知，以下均未耗尽。状态数是已发现状态数量，不是难度分。

| 检查 | 结果 |
| --- | --- |
| 基线 | `ULLDRDLURDLD`，12 次输入、2 次 Block 推动；130 状态 |
| 禁止从 E 向右穿越 | 穷尽 69 状态，无解 |
| 禁止从 E 向左穿越 | 穷尽 69 状态，无解 |
| 最近入口试验 `LR` | 玩家、Block、Gate 位置全部回到初始 |
| 错误延续 `LDR` | 穷尽 54 状态，无解 |
| 仅开放 (5,3)，禁止从 E 向右穿越 | `LDDRRULURDLD` 可解；152 状态 |

方向序列使用 U/R/D/L。两条必要性约束只过滤匹配 E 的 `gate-traversed` 领域事件及其方向，不禁止普通行走、推动或其它入口行为。公开 theorem 使用现有 API 支持的 `event:gate-traversed:right/left`（对任意入口生效），并另行执行禁止测试；精确 E+方向关系由独立枚举核验，没有伪造不被支持的组合 key。

独立绕行对照改变一个格子 `(5,3)`，让出口房南侧连通，解除必须回入口换侧的关系。并非修改规则、添加人物能力或直接把物件放到完成位置。

## 逐格封墙与保留理由

对 12 个不占用初始玩家、物件、Gate、Goal 的地面逐一封墙：

- `(0,1)、(4,1)、(6,1)、(4,2)、(6,2)`：均无解，分别承担入口另一侧接近、出口两种落点和两次推侧。
- `(0,0)、(1,0)、(2,0)、(0,2)、(1,2)、(2,2)`：单独封闭仍有解，且两个精确入射必要性仍成立。保留上下两条接近入口的可选路线，避免把题压成一条强迫走廊；不是声称这些格子机械必需。部分封闭会改变路线长度，部分不改变。
- `(6,3)`：基线封闭仍可解，作为房间可读性及单变量绕行对照的连接格保留。额外检查确认封闭该格后，再开放 `(5,3)` 无法解除 E 向右穿越要求。因此它不是基线必要格，保留用途已显式标注。

七个保留格均登记在 `readabilityElements`。不能把本审计概括为“每个格子都不可删除”。未做墙体开放全枚举，不宣称穷尽所有变体。
