# 纯空间关系能否形成高于 P 系列的规划难度？

决策已更新（2026-09-04）：P1–P10 保留为作者 D3–4 练习，不强行加难。先按[六张任务书](../../../high-difficulty/experiment-briefs.md)制作纯空间 D5–6 原型；题材只含普通推动、静态 Goal、完整占格及不可旋转形状。任务书完成不等于本 ticket 的原型与校准完成。

开始原型所需的设计假设、术语与已有锚点已具备，无须等待 01／03 的全课程实测校准完成。与 08 按单个原型迭代：原型和机器证据就绪后即可送测，反馈再用于重构；完整生产弧仍受阶段放行限制。

每关先写规则／命题测试，再有最小盘面、真实求解回放、语义必要性、有效解耦对照、宏策略与元素变异；预算耗尽或无效变体不能作证明。前置关系引用[策略主线](../../../high-difficulty/design-guide.md#strategy-lines)，评级与放行只引用[试玩协议](../../../playtest-protocol.md#high-difficulty-pilot)。

后续顺序：纯空间 D5–6 → D7–8 → 峰顶作者与专家验收 → 分配、Goal／Rain、Gate、Spike 的策略迁移 → 必要组合。不等待 Spike 铺垫地图先完成，也不因为某张卡写了 D6 就继续批量扩写。全弧仍需间隔回访和迁移证据，但第一批不提前加入这些机制。
