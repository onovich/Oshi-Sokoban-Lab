E06 已获作者组验收与 D4／D5／D6 评级，不再作为“作者尚未评分”处理。仍需区分 08／07 解出、06 观看演示，以及后续陌生样本。[同底板迁移取证](../../../playtest-protocol.md#technique-transfer-evidence)另外记录外观识别、策略认识、技巧归纳和实际运用；不能只凭“很像”或通关就宣布教学迁移完成。若比较补前置与保留三题现状，暴露条件另记，不把优化实验当作撤销现组验收。

可立即准备测试记录与受试资格核对；每个通过机器审计的原型到达后即可测试，不等待 07 的整条样板弧完成。07 的后续生产则等待对应阶段的本任务反馈，避免把生产与校准互设为完成前置。

完成条件：按协议取得各阶段样本与作者确认，证据可追溯到稳定 ID 和盘面版本；Spike 另用未见揭示的玩家完成课程顺序测试及按物件类型的回位预测。视觉／控制歧义退回修复，预算耗尽、无效对照或未覆盖状态不当作机器证明。本 ticket 不复制一套人数和评分门槛。
