## 共同约束

正交等距相机；成年人正常头身比的人形机械人；规则网格；低墙或遮挡剖切；保留多格物体完整外轮廓；编号箱体和目标对应。保留真实箱体、灰色假箱体、固定和可移动目标、蓝橙 Gate、Spike，以及雨天地面表现。雨天滑行、传送保持方向、尖刺重置和撤销等动态机制不能靠静态原画验证。Path 移动尖刺不作为本次新增玩法。

## 方案与建议实现方式

以下是美术与工程方案判断，难度是相对估计，不是性能实测。

| 方案 | 建模语言 | Web / Unity 渲染方案 | 相对成本与主要检查项 |
| --- | --- | --- | --- |
| 01 硬边低多边形 | 大块切面、少量倒角、合理人体关节 | 平面法线、顶点色、单主光与接触阴影 | 低；避免机械人关节过度简化 |
| 02 赛璐璐漫画 | 清晰硬表面、夸张装甲轮廓 | 三段明暗、轮廓线、局部网点 | 中；小尺寸下描边不能吞掉格线 |
| 03 手绘笔触 | 不对称磨损、柔和倒角、中低面数 | 手绘底色纹理、简化光照、粗糙表面 | 中；主要成本在贴图美术，笔触不能遮盖机关 |
| 04 版画排线 | 雕刻状切面、强烈明暗轮廓 | UV / 物体空间排线纹理、阈值阴影、有限强调色 | 中高；镜头缩放和角色运动时检查排线闪烁 |
| 05 像素化 3D | 低多边形正常比例角色、模块场景 | 低分辨率渲染目标、最近邻放大、调色板与抖动 | 中；编号与地面角标需单独保证可读性 |
| 06 黏土定格 | 雕塑式圆钝缺口、轻微不规则边缘 | 哑光材质、烘焙法线、柔和阴影、接触 AO | 中；保持机械人正常比例，避免玩具化 |

优先建议：02 适合同时追求强风格与规则清晰；04 最值得做强风格探索；01 适合作为低成本对照。03 和 06 侧重材质与气氛，05 需要特别测试游戏实际显示尺寸。

## 原画检查结果

六张均包含等距废土场景、正常比例机械人及机制物件小样，渲染语言有可见区别。01 仍有较多表面磨损，若追求纯低多边形应进一步减纹理；02 的 L 形物件混入竖向堆叠，建模时应恢复平面多格轮廓；部分前景墙偏高，应在实际游戏中降低或剖切。03 与 06 的差异主要在笔触和雕塑材质，模型轮廓的差异弱于其他几套。图片里的额外英文装饰文案不是产品设定。图中编号、目标数量及占格也不是已验证关卡数据。

## 后续建模约束

- 正交相机方位约 45°、俯角约 35°；游戏格作为统一建模单位。
- 箱体顶部和侧面都保留编号；多格物体用连续外壳表达一个实体。
- 可移动目标用低薄黄框，避免看成阻挡角色的高台；固定目标保持地面嵌入角标。
- Gate 用低矮装置，不能因为美术改造而产生新的方向限制。图中高度、标记和轮廓在实现前须按真实碰撞边界校正。
- 环境装饰放在棋盘外；积水和雨不能吞掉边界、编号与危险标记。
- 风格化着色需在目标引擎重建；不能假设 Blender 的材质节点随 glTF 自动等效迁移。

## 技术依据

Unity 官方的 [Shader Graph 自定义光照示例](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.4/manual/Shader-Graph-Sample-Custom-Lighting.html) 提供 Toon 光照方向；[Unity 实际项目的 Toon shading model](https://github.com/UnityTechnologies/open-project-1/wiki/Shading-model) 展示角色与环境共用风格化材质的实现。

Web 端像素路线可用 Three.js 的 [RenderTarget](https://threejs.org/docs/pages/RenderTarget.html) 与 [最近邻纹理采样](https://threejs.org/manual/en/textures.html)。这些资料支持实现途径，不代表六张原画已经达到实时一致性。
