# 场景补充原画：玩法依据与验收合同

本轮只制作并验收补充原画，不接入正式游戏，也不修改关卡。原始视觉基准：../wasteland-art-directions-20260911/01-faceted.png。原图的灰砂混凝土、锈铁、骨白与黄色标识、蓝/橙低矮晶面传送盘、红色尖刺和切面废土风格为准。已通过角色三视图 art-review/turnaround-v4.png 只用于比例尺度，不重新设计角色。

## 代码已实现的语义

- 网格四向位移，多格物体按整个 shape 平移，没有旋转。真实箱的所有组成格须覆盖 terrainGoal 或同号 Goal 才完成；Fake 可推但不计胜利，即便有数字也不算真实任务箱。
- 同一实体按整个 shape 移动。用户最新修正：3D 的 L 箱用三个标准立方模块拼接，不需要定制一体异形壳；模块接缝允许，三模块作为同一个逻辑实体移动。此前将 2D 连体边界约束扩大为禁止 3D 模块接缝的推断已撤销。
- terrainGoal 是无编号通用静态目标；Goal 有 number 与 movable，静态编号 Goal 与可移动编号 Goal 均存在。可移动 Goal 前方可放时被推，受阻时角色可穿过。用户最新指定的外观为两态升降立方体：可推时升到地面以上，与普通立方块同高；可穿透时整个立方体降到地下，顶面齐地。此前“一直低矮”的推断已撤销。升降外观尚未实现，本轮不增加手动开关或另造触发规则。
- Gate 按 nextGateId 链接；例图可采用蓝橙一对，不把“仅两端、蓝入橙出”写成硬规则。进入后保持输入方向，从出口的同向相邻格离开。出口不可用时才尝试推入口 Gate，端点移动不解除链接。Gate 为低矮可推装置，不设计成固定高大门框。
- Spike 使角色整局复位；箱/Goal/Gate 接触则回自身 origin（存在回位冲突处理），不是爆炸销毁。实体 Spike 可按 paths 沿既定路线运动，不等于角色能推动尖刺。
- Rain 是全关天气与角色滑行规则：无邻接动作时滑至阻挡前；邻接可推物时处理局部动作。不是踩到特定蓝色水格才滑，也不是水流推动箱子。
- 浅水模拟目前暂停：Board 不挂载 WaterSurface，仅保留雨线/落点飞溅。美术可画湿润材质、雨线，不以深水或强反射遮挡格线/数字，不自动重新启用模拟。来源 docs/shallow-water-rendering.md。

## 所需三张稿（独立用途）

1. scene-kit：1格地面、整块破墙/转角/门洞通道、锈钢支撑、场外峡谷碎石模块；含正交ISO视线示意，以及同一小场景晴/雨外观。游戏通道净空、可走格与场外装饰清楚；高墙只在后部，前部采用低断墙设计提案，不声称已有自动淡出。雨天保持同布局可读性。
2. gameplay-props：标准立方单箱、三个等尺寸立方模块拼成的 L 箱、Fake 空心架、通用固定目标、同号固定目标、可移动目标的升起/下沉两态；正交 ISO+准确顶视占格。L 占格为 (0,0)、(0,1)、(1,1)，空缺 (1,0)，不压短任何模块。数字为匹配身份；所有水平顶面数字采用同一世界方向：顶视字顶朝图上方，基线平行世界 X，ISO 随表面投影，不朝屏幕单独旋转。固定目标齐地；移动目标刚体垂直升降，两态顶面编号、大小、朝向、黄色护角保持一致，不缩扁几何。尺寸仅为格子相对规格。
3. devices：蓝/橙传送盘的低矮结构、同一端点的待机/激活外观（状态提案），红色尖刺的基座/静态和路径移动外观、触发回位视觉提案。机关形状属于真实玩法，效果仅美术提案。若画传送方向或前后状态，必须按上述规则，不能画固定门或可推动尖刺；不画溶解、血液、永久毁坏。

## 硬性验收

风格需与原场景一致；不加魔法圆环、霓虹赛博城、蒸汽管道迷宫、浮空岛、武器/战斗系统。关键轮廓能由 Blender 网格/顶点色/常规实时材质实现。地板格线用于推理，不被碎石占满；装饰不能看起来像可推任务箱或目标。编号与占格外形可读，状态变化不改变占格或零件身份。

图像主 agent 逐张独立验收；subagent 自检不等于通过。与规则、身份、占格、风格冲突退回重做。背景轻微色差不是玩法结构错误；不能为追求纸背景像素完美反复修改已正确主体。原画不是关卡文件，例图不声称可解关卡。图中尺寸、灯效、安装细节均为设计提案，不是精确测量。
