# 怎样反复利用并升级 Goal 数量与玩家占位认知？

把“允许空 Goal”“玩家不参与胜利”从基础定界迁移到资源安排。只记录新玩家自然出现的过度归因，不向已掌握规则的玩家重新灌输误解。后续问题是选择哪个目标留空、何时暂用、何时释放；静态 Goal 不因图标变成阻挡物，可移动 Goal／Rain 的地形用途属于之后的机制迁移。

首批纯空间研究入口为 [E03](../../../high-difficulty/experiment-briefs.md#e03)，不是提前制作 Goal／Rain 组合。完成条件：回访增加新的规划责任，规则定界能排除偶然站位归因；目标选择与运输／暂存相互约束的必要性须由真实地图和解耦对照证明。评级与放行引用[试玩协议](../../../playtest-protocol.md#high-difficulty-pilot)。
