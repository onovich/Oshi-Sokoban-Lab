# 通用解法演示

## 需求与边界

2026-09-04，作者在 LAB 11「再借庭」暂未解出，要求一个点击即可演示解题步骤的通用功能。只增加主动请求的解法播放，不调整盘面、引擎、课程顺序、解锁规则或存档结构；不把观看演示计为独立通关或难度校准。

操作入口位于开始关卡后的控制区：**演示解法**。默认从该关的起点求解、自动播放，提供暂停／继续、单步、重播和返回。按 Esc 也可退出；正在进行的玩家局面、撤销历史和剩余时间保留。不是从玩家可能已死锁的当前状态续解。手动方向、Z、R 在演示中不操作隐藏的玩家盘面，仍可切换关卡来取消演示。

不会自动演示，不提供常驻答案或普通提示。演示终局显示“演示完毕”，不出现下一关、不解锁课程、不写入完成记录；返回后恢复的是进入演示前的真实状态（包括原先已完成的状态）。

## 实现分层

- `solver/solution-search.ts`：调用真实规则求解器，只取可回放见证，不运行作者面板的命题反事实审计。200,000 状态预算、零额外成本窗口、一条结果；不宣称路线独一或全成本最优。
- `solver/solution-request.ts` / `solution.worker.ts`：搜索放在模块 Worker，避免阻塞界面。20 秒额外墙钟上限，完成、错误、取消或超时都终止 Worker；不支持 Worker 时明确失败，不回退到主线程长搜索。消息校验与取消隔离防止旧结果影响新关。
- `rendering/solution-replay.ts`：每一步再经 `move()` 校验，拒绝非法方向、无效动作、失败局面和未通关路线；最多接受 10,000 个操作。记录真实领域事件和本次 GateTraversal，不复制第二套移动规则。帧不携带累积 Undo 历史。
- `components/SolutionDemo.tsx`：拥有独立播放状态；App 的玩家 `GameState` 不参与演示。正在求解、预算耗尽、穷尽无解、运行错误和播放完成分别表达。预算耗尽绝不写成无解。

步间保留 600ms 阅读间隔；一次动画完全结束后才计这一步已呈现并允许下一步。普通移动为 200ms；Gate 两段与间隔共 364ms；Spike 销毁／重生完整 820ms，减少动态模式为 80ms 接触闪光。普通与 Gate 时间由 Board 和播放器共享；减少动态下普通移动、Gate 均直接呈现最终状态，不产生入口角色副本。还修正了普通 Board 的减少动态 CSS：隐藏 Gate 入口副本，避免取消动画后入口角色残留。重播重建表现层，避免从终点直接飞回起点。暂停停止后续操作，不截断当前动画；退出立即取消整个演示。

限时关的演示是操作序列讲解，不以慢速播放的墙钟耗时证明时限内能完成。玩家的时钟在观看期间暂停。
