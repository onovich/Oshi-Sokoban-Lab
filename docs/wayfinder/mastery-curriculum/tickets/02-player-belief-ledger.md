# 玩家会形成哪些有用但不完整的信念？

为 Goal、玩家占位、Spike / origin、Fake、footprint、Rain、Gate 分别记录：信念主张、形成它的真实证据、合理过度概括、反证所需单变量、打破后的完整模型、可迁移场景，以及可能因视觉歧义产生的伪信念。

另记 E06 作者描述的“需要反复改变同一个块的状态，不能指望一步到位”这类策略认识：它不精确，但可以正确且有用，不必为了安排“打破”阶段将它捏造成错误规则。同底板再现可以用于巩固、限定或迁移，不是每次都要反转玩家的认识。策略认识与可归纳技巧的区别见[术语表](../../../../CONTEXT.md)。

完成条件：每条信念都有 `seed / reinforce / stress / overturn / transfer / synthesize` 位置；任何没有足够前置证据的“反转”必须退回铺垫阶段。
