## 本轮推进的范围

沿用获作者认可的 E02 教学思路，但不宣称已经复制了它的成功：先减少并发任务，表达局部关系；再保留可识别底板，让新增任务与旧任务争用操作空间。本轮先交付两关，不以弱变式凑成三关。是否补第三关由学习反馈决定。

这是 E03 设计卡的首段实践：从“允许空 Goal”转向“一个已经完成的物件，为什么仍须离开这个 Goal”。尚未覆盖多个可行最终分配的高阶全局选择。不能把这两关标成整个全局分配策略弧已经完成。

## 盘面与底板亲缘（以下含设计剧透）

符号：`@` 玩家，`A` 同一竖向两格物，`B` 同一横向两格物，`C` 单格物，`G` 静态通配 Goal，`#` 墙。上下相邻的 A、左右相邻的 B 各自是一个整体。

小庭：

```text
G.G.#
#.CA#
#G@A.
#G...
```

偏庭：

```text
G.G.#
#.CA#
#G@AG
#.BB.
#....
```

偏庭 `(3,2)` 的 Goal 被初始 A 覆盖，图中写作 A；它与右侧 `(4,2)` 构成横向目标。真实绘制仍沿用现有覆盖层，不新增颜色或图标规则。坐标从左上 `(0,0)` 开始。

可读性待验收项：浏览器检查确认初始 A 会遮住上述 Goal，移动 A 后才露出完整目标图案。本轮未修改共享渲染器；不能把求解通过当成静态表达通过。若这个遮挡影响识别或导致试错，应作为表现缺陷修复，不计合理难度，也不视为成功的认知误导。

亲缘父题是 `lab-e02-return-loan`，保留上方走廊、A／C 初始关系和东侧绕行口。父题的顶部多格目标改为西南竖目标及东侧横目标；C 新增一个近处可暂时完成的位置。不是在已验收地图上补装饰 Goal：最终分配、运输方向与收尾条件已改变，作为独立新 ID 保存。两张新题之间则保持上半部锚点，第二题增加横物与它争用的底部／东侧空间。

## 学习单位与因果关系

### 小庭：局部完成不是最终承诺

- 可见条件：C 上方有近 Goal，远处还有单格 Goal；A 的竖目标位于西南。
- 主命题：C 必须先到近 Goal，让 A 横移；之后 C 必须离开近 Goal，玩家才能使用上排空间安排 A 的向下收尾。
- 必要中间态：C 暂时完整覆盖 `(2,0)`；A 获得让路空间；C 去往 `(0,0)`，释放 `(2,0)` 与通向 A 上侧的道路。
- 合理第一计划：“C 已经完成，只需要继续做 A”。玩家可由自己的到达路径发现，这一局部完成不能保留。
- 终局：A 在 `(1,2)`，C 在 `(0,0)`；近 Goal 空着。玩家没有归位要求。

### 偏庭：释放 Goal 之后还要协调另一个任务

- 新增判断不是再走一遍更长路线，而是横物 B 的移动会占用 A 操作所需的东侧／南侧位置。
- C 的暂时完成与释放仍不可绕过；A 先向左借位，B 才能右移到可继续操作的位置，再安排后续收尾。
- 禁止 A 在 B 完成前移动，无解；禁止 B 在 A 完成前移动，也无解。因此不能把两项任务作为独立小题，整件先后完成。
- **不强制唯一最终完成顺序。** 实际搜索发现 B 可以先于 A 最后完成，只要此前已经交错准备。已淘汰“必须 A 最终完成后才可完成 B”的过强设计断言，不把一种合法换序误判为绕解。
- 终局：A 在 `(1,2)`、C 在 `(0,0)`、B 在 `(3,2)`；近 Goal 仍空着。

## 反事实与证据边界

实际检查使用真实 `move()`，不复制推动规则；小盘面 oracle 不使用启发式死锁剪枝。

1. 两关均可从初始状态求解并回放至胜利；第一关演示为 14 步，第二关 BFS 见证为 32 步。步数不是难度证明。
2. 禁止任何物件进入 `(2,0)`，两关均穷尽为无解；允许进入但禁止释放，也均无解。
3. 枚举全部可达终局，包含交换身份和其他目标分配的可能；分别只得到上述一种物件位置分配，且 `(2,0)` 在所有终局都空着。唯一终局不等于唯一解法或人类难度。
4. 近 Goal 初次被 C 覆盖时，C 确实完成、全局尚未完成；Undo 与 Restart 可恢复。
5. 打开西侧 `(0,1)`、`(0,2)`、`(0,3)` 构成独立玩家绕行路，保持所有物件和目标不变，并禁止物件使用新增格：即使禁止释放近 Goal，两关仍可解。这个对照解除的是步行访问条件，不给箱子新增暂存区。
6. 去掉 `(2,0)` 的 Goal 标记，保留普通地板：原解仍成立、同一求解见证不变，但 C 的中途完成反馈消失。该标记的职责是**认知／可读性对照**，不是碰撞规则或新增物理技巧。玩家是否因此改变“已完成就不动”的计划，必须通过试玩确认。
7. 逐项删除物件／Goal、封闭初始空地：小庭 13 项，偏庭 17 项；没有未解释的冗余项或预算耗尽项。唯一 `readability` 项是临时 Goal。小庭 `(1,1)` 封墙后仍有不同解，不把它冒称为所有解都不可缺少；它服务于直接可读的横移后下推方案，封墙会改变求解路线。
8. 物件删除让引用其事件的证明失效，不能单凭这一项宣称“任务耦合”。偏庭另有上述双向任务禁用检查，专门核验不能独立整件完成。

反例记录：曾试在 E01 暂存位置补齐两格 Goal，结果 A 留在暂存处、B 直接完成就赢，释放不再必要。该候选未发布。地图搜索只辅助寻找可行配置，最终候选按因果关系和对照选取，不按搜索状态数评难度。
