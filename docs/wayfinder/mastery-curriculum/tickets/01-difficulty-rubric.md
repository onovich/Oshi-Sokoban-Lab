# 怎样定义并校准 Oshi 的 1–10 难度？

产出一套可校准量表，区分规则回忆、技巧识别、关系迁移、计划重组、资源冲突和执行尾巴；机制数量、动作交替次数与搜索指标不能直接评分。作者、陌生真人、AI 的原始意见分别保存。

已有[设计目标与反例](../../../high-difficulty/design-guide.md)及[试玩协议](../../../playtest-protocol.md#high-difficulty-pilot)，但陌生校准尚未完成。除 P／E01 的 D3–4 外，新增[作者认可的短庭 D4、旁路 D5、回环 D6](../../../playtests/2026-09-04-author-e06.md#author-acceptance)；06 在观看完整演示后评级，不隐去暴露条件，也不拒收作者判断。不得通过改标签虚构 D1–2。

技巧可归纳性与难度、关卡可用性分别记录。E06 能用但教学仍可优化，不因“朦胧认识”就自动降分或否定关卡。完成条件仍是在不同原型与相应真人测试后取得各档正例、边界和证据；一组已有作者评级不等于整个量表校准完成。
