# 怎样让避刺直觉充分成立后再公平地打破？

设计一条跨早期基础课和中后期进阶课的 Spike 认知弧，而不是连续三关的短前导。Spike 先在至少三个非 Spike 关卡族之间以新增桥接关的形式分散出现，只承担辅助障碍：封锁推侧、破坏诱人捷径、限制完整 footprint 或截断 Rain 停点。不得为此修改任何已验收盘面。桥接关的标题与任务仍属于所在时期的主要技巧；触刺应真实地损失有用布置，不能靠主动回位抢走主要命题。各类路径的成本比较以统一协议为准，不能因某条错误路径经重置得到恢复就声称整个关卡违例。

采用既定 H1–H8 分散铺垫，暴露之间保留非 Spike 关卡，第 70–75 槽为正式回位揭示。只有顺序盲测通过，才确认认知弧成立，不是重新由猜测调整槽位。具体前后边界见[总纲](../../../high-difficulty/design-guide.md#spike-belief-design)，各类型回位许可分别核验，不以“原位必须空无一物”代替规则。角色死亡仍是独立整盘重置。

完成条件：各桥接、揭示及迁移关附主技巧、信念证据、回放、重置禁用与删除变异；机器成本条件和真人比例只按[Spike 试玩专项](../../../playtest-protocol.md#spike-belief)。冻结清单证明旧关零变更。`lab-spike-*` 三个未验收原型不证明长期铺垫；本期只同步策划，不生产这些地图，其生产顺序服从纯空间样板验收。
