# 实体归属与格边接缝

日期：2026-09-04。触发反馈：作者在 LAB 11 指出，相邻白块和右侧连体竖条难以区分。这是视觉可读性反馈，不是难度评级，也不能据此推断作者采用了什么解法。

## 视觉合同

- 相同物件的相邻组成格连成完整实心面，不画内部格线。
- 不同物件保持独立、清晰的外轮廓；描边叠在原占格表面内部。
- 不缩小物件、不加入格间距，不改变形状、碰撞、目标或动作规则。
- 保留真实 Block、Fake、角色的既有语义配色，不分配新的身份颜色；Rain、Goal 和 Gate 的视觉语言不变。

## 原因与修正

原渲染已按实体形状省略内部描边，但每格仍独立绘制 SVG。实际测量中，相邻轨道出现 `133.59375 × 133.609375` 等非整数且略不等边的尺寸；默认 SVG 等比居中和抗锯齿会产生并非物件边界的细缝。原外轮廓仅 1px，难以与该细缝区分。

实心方形投影改用 `preserveAspectRatio="none"` 与 `shape-rendering="crispEdges"`，直接覆盖实际格边。物件轮廓在原位置内描，宽度改为随视口变化的 2–3px。同一物件内部仍为 0px 描边。Goal、Spike、Gate 不采用实心方形的像素对齐设置，保留原绘制方式。

实现仅涉及 [GameGlyph](../../src/components/GameGlyph.tsx) 和 [样式](../../src/styles.css)，渲染回归位于 [Board 测试](../../src/components/Board.test.tsx)。引擎、关卡、进度和选关未修改。
