## m01

初始判断：双格白块位于两个黄框目标上方；右侧墙限制了绕行。先尝试移动目标为自己让路。

实际输入：`LUDLU`；重开；`LLLUURDLDR`。无撤销。

观察与预测修正：白块为整体，第一次上推虽打开中行，但将白块困在顶边。目标遇到阻挡时角色能站入；从目标上离开时目标不跟随。重开后绕上方将白块下推，只有一格覆盖目标；从左侧右推白块时，已重叠目标留原位。未能找到完整覆盖并保留站位的路线。

可读性：黄框目标与黄色角色叠合时不易一眼区分；“可推动 Goal”不直接传达阻挡时可穿入。白块连续画面能看出整体。尝试是定向规则实验，未随机撞中胜利。未回访，不把后关经验算首次。

## m02

初始判断：可把目标移到顶行白块所在位置。

实际输入：`RDRU` / `RLDLU` / `RRUL`，13步完成。

第一次四步验证失败：Goal 从下推向白块没有进入白块所在格，角色站进了 Goal。修正为先把 Goal 搬到白块左侧 (2,1)，再绕到右侧推白块左移。后九步完全按预测成功。不是随机命中。规则校正之后路线短且清楚。

## m03

初始判断：白块1/2须对应目标1/2；必须留出右侧绕行口。

实际输入：`UURRDRDL` / `UULLDRURD`，17步完成。

## g01

初始判断：旋涡应互相传送；左下角墙导致左白块不能直接下推后右移。

实际输入：`RD` / `LUURRDRDL` / `UULDRUULD` / `ULLDRRURD` / `LLDRULD` / `LDRD`。

先发现进门会沿原方向在另一门外一格出现。将右白块放在出口下方，预测从另一门出场能推动它；实际入口门被向下推到左盘 (3,3)。这个意外让我发现可移动门，并据此完成左白块。随后预测右门能连推其下白块，一次 D 无效；修正为利用已完成的左白块堵住右向出口，横推右门让出站位，最后下推右白块完成。两个具体错误预测，没有盲目试方向。

可读性：旋涡像传送器，但初态未直接提示可推。必须理解“出口受阻会移动入口门”与“门不能连推白块”。首次发现这些规则形成主要负荷。

## g02

初始判断：可以先完成左下白块，再移门让右白块绕到下排。

实际输入：`LULLLDDR` / `UURULRDLDLDR` / `URURDLU` / `RULDLDRRR`。

先完成左目标并右移下门。把第二白块移至下行后，预测白块也能推动被堵出口的门；一次 R 无效。修正为玩家先从门下方推门向上，利用另一端上边界阻止传送。腾出下排后绕回左边，将白块连续向右送上目标。主要路线有事先预测，不是随机命中。

可读性：通过前关经验，门的移动逻辑逐渐可用；玩家能推门而白块不能推门的差异仍需要实测。

## g03

初始判断：白块必须最终进入第2行向右推上目标，门占据所需站位；灰块可能是阻挡出口的道具。

实际输入：`ULLURRU`（最后 U 为原地传送，步数增加但位置不变）；重开；`DLDRRUL` / `DLLDRURRDL`。

先将白块推到目标下方，但无法在门格站立以完成最后横推。原地传送实验确认出口与原站位相同也会计一步。重开后把白块放到下门左出口，成功将上门左移；随后预测白块可被推入门并出现在上方，实际推向门无效。白块留在底行，门与站位互相卡住，未找到后续。

未解出，不把脑内路线算成功。主观高：需要连续安排门位置、出口阻挡、可站立位置，同时新灰块用途尚未通过成功操作确认。白块无法像角色传送这一点此前并未有充分的正向教学。灰块与真白块的视觉差别清楚，但性质需试验。
