## 作者证据区（包含解题结构）

### 从失败样本到本轮选择

[E01 作者反馈](../playtests/2026-09-04-author-e01.md)否定了其高难目标，但不否定已证明的暂存必要性。经[五张后续任务书复审](post-e01-review.md)，本轮选 E06 的三任务交错，不把 E01 变长。构造时曾用调用真实规则的可逆局面搜索定位候选，随后逐项检查资源解释、反事实和裁剪；搜索量与交替次数没有被当作难度评分。

### 盘面与隔离

```text
###@G.
###BAG
..C.A.
...G.#
...G##
```

同一个 A 是不可旋转的两格竖物；B、C 是单格真实 Block。`G` 为静态 Goal，`#` 为墙，`.` 为地板。左上角为 `(0,0)`。只有普通推动；晴天，无 Fake、编号、刺、门或可移动目标。初始四个 Goal 都无遮挡。

- 主版 ID：`lab-e06-interleaved`；对照 ID：`lab-e06-independent-return`。
- 对照仅把 `(2,1)` 的墙打开，所有任务、物件、玩家起点、Goal 与规则不变。两版有意共用实体 ID；关卡进度 ID 不同。
- 只追加 `mastery-v2` 实验室组。实验室从 5 关增至 7 关；正式可玩 70 关、120 槽蓝图、60 个冻结关、P1–P10、E01、存档格式与引擎均不改。

### 资源关系与可接受的换序

本命题不是“存在一个 A、B、C 的完成顺序”，而是必须交错制造这个顺序的执行条件：

1. B 先向下暂存，使 A 可以向左调整；B 又要转入西侧 `(1,3)`，让 A 暂时完整覆盖下方两个 Goal。
2. C 的上移需要玩家站在 `(3,3)`，因此已完成的 A 必须左移到 `(2,3)`；C 随后上移到 `(3,1)` 暂存。
3. B 才能从西侧暂存位转出。C 的上方暂存又会妨碍 B 的最终推侧，因此 C 还需下移，不能就此顺次做到底。
4. B 腾出的 `(1,3)` 让 A 可以第二次向左暂存；这次开放的是南侧返回西侧的通路，供玩家取得 C 的左推侧。然后才能完成 C，并恢复 A 的完整覆盖。

A 的两次左移之间有 B 的实际占位约束，不能连续提前完成。B 最后一推与 A 第二次左移之间存在合法换序，测试保留它；不能为制造“唯一解”禁止同样满足资源交接的方案。这里只验证了一处关键三方交接，不宣称穷尽了人的全部解题策略。

对照新增 `(2,1)` 的返回站位后，存在 A 完整覆盖后不再离开、同时避开上述交接序列的解。它解除真实依赖，而不只是减少步行。

### 必要性与工具边界

采用相互独立的两类禁令：

- 状态关系：禁止 A 从完整覆盖变为未完成。主版穷尽无解，对照可解。
- 有序交接：A `(3,3)→(2,3)` → C `(3,2)→(3,1)` → B `(1,3)→(1,2)` → A `(2,3)→(1,3)`。主版禁止它后穷尽无解；对照即使同时禁止这段交接与 A 撤回完成，也有真实回放解。

事件坐标绑定本版本的资源位置，不是一般的人类推理深度定义。最后事件是开放返回通路，不是任何解都会发生的获胜推动。另筛查三任务六种“逐件做到底”排列，均无解；这只是补充证据，不把推动交替次数称为思考层数。

实验室无剪枝 BFS 继续调用真实 `move()`。本轮仅增加有序条件的有限前缀进度，并纳入状态去重，避免把位置相同、历史约束不同的状态合并；以可重复到达同一位置的回归盘面检验。没有新引擎规则或第二套推动逻辑。状态局部回调仍不得私自依赖历史；预算耗尽始终为未知。

推动数是最短移动见证上的计数，不额外宣称全局最少推动。作者分析调用 `analyzeLevelForAuthor(spec, { maximumStates: 100_000, maximumPlans: 8, pushSlack: 2, moveSlack: 8 })`；成本窗口为已找到最佳移动数 +8、对应最佳推动数 +2，最多展示 8 条宏计划。展示被截断，不能证明唯一核心策略；也不把窗口外方案排除为不合法。主版预定最后交接之后，最佳见证还有 **5 推**；这是自动检查点的尾巴，真人最后理解可能更早，尚待记录。对照的旧工具尾巴字段在未触发该检查点时回退为整条路线推动数（17），不是人的顿悟尾巴。

两条合理误选另有真实回放检查：开局 `→↓` 先将 A 推向下方，或 `↓↓↓` 将 B 完成在最下方 Goal，后续都无正常推动解；Undo 最后一步即可恢复可解，Restart 精确恢复初态。这两条是测试场景，不是已经观察到的玩家行为。

### 变异与元素职责

裁掉三格不影响原解与必要关系的地板 `(1,0)`、`(2,0)`、`(0,1)` 后，主版为 **6×5、21 格可进入区域**。主版最短移动见证与关键依赖仍成立。当前 19 个有效变异结果为：

- 删除任一 3 个真实物件：工具报告命题绕过。但事件序列引用了被删除的实体，该结果本身只是机械缺失事件，不能据此证明资源参与；以下另查仍存在的任务。
- 删除任一 4 个 Goal：无完整覆盖解。
- 封闭任一 12 个初始空地：无解，承担推侧、运输或返回通路。

没有无效、预算未知或未解释的冗余结果。起点、实体和 Goal 占格不做非法初态封墙；边界墙限定盘面，另用唯一的返回站位开墙检验解耦。此结论仅覆盖声明的变异集合，不是任意地图改动的全覆盖证明。对照故意允许绕解，不做以原命题必要性为前提的删格审计。

对物件删除的独立检查不再引用已删除实体：禁止任何存活 Block 失去完整覆盖，主版穷尽无解，删除 A 或 C 后均可解；禁止仍存在的 C 暂存到 `(3,1)`，主版穷尽无解，删除 B 后可解。这些有效回放说明删除确实改变了剩余任务的准备要求，而非仅缺失事件。它们支持各物件的资源职责，不代表删除变体也经过人类难度校准。

### 可读性修正

独立 Chromium 初次读盘发现 A、B 紧邻时白色面会融合，像同一件 L 形物。补充渲染回归后，为真实与 Fake Block 绘制物件外轮廓：细线叠在满格表面，同物体相邻组成格不画内部线。没有缩小 glyph、增加格间距、改变碰撞或关卡数据；仅修复形状归属的歧义。沿用现有语义配色与键盘交互，不增加目标分组或规则提示。

### 浏览器与回归

独立 Chromium 存档中用正常动画按键完成两版，检查 Undo／Restart、回环“下一关”进入旁路、末关停留与实验室进度隔离；无页面脚本错误，未访问或改动用户浏览器存档。轮廓修正后在 320／768／1024／1440px 复查作者面板展开和收起无横向溢出；测量相邻物件边界仍相接、同物件内部无边线，并查看 320／1024px 截图。键盘方向、Z、R 与按钮 Tab／Enter 可操作。

无障碍检查仅覆盖上述键盘、现有语义与新增图形对比，不声称完整 WCAG／axe 审计。轮廓使用既有 `--field-charcoal`，对真实物与 Fake 面色的对比分别约 15.35:1、3.23:1。
